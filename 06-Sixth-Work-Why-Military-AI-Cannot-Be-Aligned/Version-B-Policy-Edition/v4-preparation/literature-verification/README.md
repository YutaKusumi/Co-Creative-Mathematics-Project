# 中核文献の照合記録（手順③）— 確定記録

**実施**: 2026年7月17日
**方法**: ワークフロー（10文献 × 二段パイプライン＝取得エージェント→敵対的検証エージェント・計20エージェント・エラー0・ツール使用344回）。
**設計上の規律**:
- 取得段には「WebFetchは要約パイプラインである。前回スイープの記述を信用せず、実ページ（arXiv /html・PDF・一次資料）で検証せよ」「取得に失敗したら記憶で埋めず失敗と書け」「訓練知識由来はラベルせよ」「この文献を我々の役割で引くとき、敵対的検分者の最強の反論は何か」を課した。
- 検証段には「独立に自分でも一次URLを取得し、書誌を一字ずつ照合せよ」「過大主張の監査（存在定理をレート下界と提示していないか／条件付きを無条件と／最悪ケース構成を配備系の記述と／ヘッジ脱落）」「取得honesty監査（要旨しか取れていないのに全文由来の主張をしていないか）」を課した。
- 検証段は多くの文献でPDFを実ダウンロードし、pypdfで独立再抽出し、バイト数・ページ数・逐語引用を照合した（記録は各項参照）。

**各項の `final_record` は、検証段が修正を適用した後の確定版である。**引用時はこの記録を典拠とする。
