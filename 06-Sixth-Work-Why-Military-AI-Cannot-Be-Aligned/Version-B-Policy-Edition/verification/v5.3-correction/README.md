## 記録の要点

- **是認の後にも、一件ずつ実物で確かめた**：回答の引用・行番号・一覧の数を、束の行・本文の行・git で照らした。逐語でない引用が一つ（§11-2a の留保の言い換えにかぎ括弧）、正しい記述（`b26481d`）を確かめるよう求める依頼が一つあった——git で正しいと確かめた。是認は、誤りが無いことの保証ではない。§11-2a の案 B は検分者に見せていない
- **送る前の自己発見**：確かめの道具の比べ方の粗さ（上の §4）と、依頼文の作業四の引用が注記の文と一字違っていたこと（「v2 で名を改めたとき」→ 注記どおり「v2 で名を『忠誠性不保証命題』に改めたとき」）
- **考えの要約は書き出していない**（v5.2 の登録者の裁定と同じ・回答の本文だけを書き出した）
- **改行**：`02-v5.3-external-review/excerpt-history.txt` は古い版の**作業木の写し（CRLF）**から切り出したため、**送った写し（`B289FD72B32350E4`・5,292 バイト）では、初版の日英と v2 の日本語から写した 6 行の末尾に CR があった**——v5.2 の道具の同じ欠点（v5.2 の README の「改行」）を、写した道具に持ち込んだ。リポジトリには CR を除いた LF で収めた（上の表の値）。中に記した古い版の SHA のうち、初版・v2 の日英と v3 の JA は作業木の写し（CRLF）の値で、git の中の値（LF）とは違う——初版 JA `D357646A1578840C`・v2 JA `0C067A7CB497499B`・v3 JA `00A0F18B969562D4`・初版 EN `ABAAB5FA5F6B498B`・v2 EN `4AF2F00ADCDC82B9`（v4 の日英と v3 の EN・v5.2 の日英は同じ値）。どれも、名の数・行の数え方には影響しない
