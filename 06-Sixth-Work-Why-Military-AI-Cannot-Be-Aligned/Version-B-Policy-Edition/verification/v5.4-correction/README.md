## 記録の要点

- **是認の後にも、一件ずつ実物で確かめた**：回答の行番号（21 か所）・一覧の行数を、束の行と本文の行で照らした。一覧に無い節を挙げた言い方の不正確が一つ（判断の中身には響かない）。是認は、誤りが無いことの保証ではない
- **送る前の自己発見**：§12-2a の直し漏れ（洗い直しの grep の出力にあったのに、行の頭しか読まずに見落とした——作った版の機械の数えで見つけた）・経緯の言い方の不正確（英語版の初版の言い回しは v2 と違う——「英語版は v2 で訳し直されて言い回しが改まったが、限定のない形は同じ」を添えた）・確かめの道具の自分の誤り二つ（計画書の追記 1）
- **考えの要約は書き出していない**（回答の本文だけを書き出した）
- **改行**：`excerpt-history.txt` は古い版の**作業木の写し（CRLF）**から切り出したため、送った写しには行の末尾と抜粋の切り出しの中に CR が 60 あった——v5.3 の README の「改行」と同じ欠点を、写した道具に持ち込んだ。リポジトリには CR を除いた LF で収めた（上の表の値）。`sweep-v5.3-negations.txt` は Windows の標準出力から書いた CRLF——LF にそろえた。どれも、数え方と行の中身には影響しない
- **公開の写しで伏せたもの：なし**——チャットの URL は、はじめから記録に書いていない。計画書は手元の記録（動画の作業場の `24-source-v5.4/01-source-correction-plan-v5.4.md`）と同一
- **道具**は起草者の手元の絶対パスを参照するため、そのままでは実行できない——**中身の検分用**。`verify_v5_4.py` が書き出す人の目のための差分（`build/`）は収めていない（git の履歴と `02-v5.4-external-review/diff-v5.4.txt` で足りる）
