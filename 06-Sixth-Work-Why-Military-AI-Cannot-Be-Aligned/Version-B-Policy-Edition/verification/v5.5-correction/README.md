## 記録の要点

- **是認の後にも、一件ずつ実物で確かめた**：回答の行番号と「-」の側の文言（十二か所×日英）・v5.5 の側の文言を、束の行と本文の行で照らした。記述の誤りが三つ（節の位置・一文の位置・第8章の役割〔不成立を「受けて」と書き、条件 β > 1 を落とした〕）——判断の中身には響かない。是認は、誤りが無いことの保証ではない
- **〔軽微〕一件は観慈の見落とし**：冒頭の「本論文を読む際の注意」の第7章の参照〈第7章7-3（ゲーム理論前提の崩壊）〉は、洗い直しの grep の出力に出ていたのに、出力を行の頭で切って読んで見落とした（v5.4 の §12-2a と同じ型の二度目）。確かめの道具の残りの数えの型も「の」の無い形と英語の形を数えていなかった——直して作り直した
- **一般知識の答えは二つの個体で向きが逆**：v5.5 の確かめの個体は、直す前の言い切りを「明らかな言い過ぎ」と答えた（差分で直しの向きを見せ「言い過ぎだったか」と問うた）。九本目の動画の二巡目の個体は、v5.4 の言い方の一つを「非協力ゲーム理論の標準的枠組みに照らして正当な指摘」と答えた（v5.4 の抜粋だけを渡し「正確か」と問うた）。同じ資料での比べではない。**どちらも一つの目の申告で、v5.5 の直しの根拠ではない**——直しは本書の中の整合（§7-1b の範囲・§7-3a の「正確に知ることができない」・特徴三の本文の「直接的に」）に拠る
- **考えの要約は書き出していない**（回答の本文だけを書き出した）
- **改行**：`excerpt-history.txt` は古い版の**作業木の写し（CRLF）**から切り出したため、送った写しには行の末尾と抜粋の切り出しの中に CR が 40 あった——v5.3・v5.4 の README の「改行」と同じ欠点を、写した道具に持ち込んだ（三度目）。リポジトリには CR を除いた LF で収めた（上の表の値）。数え方と行の中身には影響しない
- **公開の写しで伏せたもの：なし**——チャットの URL は、はじめから記録に書いていない。計画書・事前登録・検算・回答は手元の記録（動画の作業場の `23-source-v5.5/`・`24-external-review-2/01-response-gemini-verbatim.md`）と同一
- **道具**は起草者の手元の絶対パスを参照するため、そのままでは実行できない——**中身の検分用**。`verify_v5_5.py` が書き出す人の目のための差分（`build/`）は収めていない（git の履歴と `02-v5.5-external-review/diff-v5.5.txt` で足りる）
