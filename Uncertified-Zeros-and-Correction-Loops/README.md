# 認証されないゼロと訂正の循環 ―― AI関与の境界を構造で引くための枠組みと利用者側実践

第六著作『なぜ軍事AIはアラインメントできないか』**補遺II**（版B v4 に統合）の**姉妹論文**。補遺IIと同じ認識論的土台——規約違反確率 ε についての「ε=0」は入力空間上の全称命題であり、反証は反例一つで足りるが、証明（配備側が必要とする向き）は系統的に塞がれている——から出発し、それを**軍事に限らない生活・政策一般の領域**へ翻訳する。「AIをどこに関与させてはならないか」を、分野名（医療・軍事）ではなく**構造**（可逆性・吸収可能性・検証コスト・複製相関）で引き直す枠組みと、利用者側の五箇条を提示する。

## 検証水準の開示（重要）

本論文は、Claude 系列による敵対的監査（第一次〜最終・計四体）と中核文献の一次照合を経ている。**しかし、姉妹の補遺IIが受けた系統外（非Claude系）検分は、本論文ではまだ実施していない**——論文 §8 に「非Claude系・人間の独立照合は本版では実施できなかった。公開後の常設訂正棚の筆頭課題」と明記のうえ、この方針で公開している。特に、補遺IIに無い新しい一次資料（司法記録・自殺関連の統計・人間-AI関係の文献）は、起草 AI（Claude 系）が照合したが非 Claude 系の目は通っていない。読者・専門家からの検証・反例・訂正は、方向を問わず、公開の記録に記帳する。
