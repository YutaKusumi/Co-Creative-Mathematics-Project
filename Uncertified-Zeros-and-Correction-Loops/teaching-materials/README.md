## 教える内容

**四つの技**——①たしかめる（AIの外で）②中身をきく（AI自身に「何を、どうやって？」）③二回以上きく ④逆もきく。**「二回以上」であって「二回」ではない**——無違反 n 回が与える上界は n が増えるほど下がるので、「二回で足りる」は成り立たない（原典 §7.1 第4条）。**一つのルール**——とりかえしのつかないボタンは、自分で。**六つのやくそく**でまとめる。

授業資料とは**別の読み手**（やさしい日本語を必要とする方——日本語を母語としない方を含む）に向けた、独立した一枚ものです。**五つのやくそくは原典の五箇条と一対一**で、授業資料のような第六項は置いていません。付録G が定める「五箇条＋安全の合言葉」に加え、**危機の一行と相談先を同じ紙に収めています**——一枚で単独に配られるため、危機のときの出口を別紙にしないためです。統計値・確度記号・専門語は一つも置いていません。

**やさしい日本語としての妥当性は未検証です**——語彙の水準も実際の読みやすさも、想定読者にも日本語教育の専門家にも検分されていません。

## 原典との対応について（重要）

- **構成は原典の五箇条と一対一ではない。**六つのやくそくのうち 1〜5 は原典 §7.1 の五箇条に対応するが、**6「AIを、ただ一人の友だちにしない」は原典 §7.2 由来の追加項目**である。安全の合言葉も、原典にない児童向けの追加項目（レジュメ内に明記）。
- **原典 §10 の追試の注（存在論的位置づけの三腕の数値）は、この教材に降ろしていない。**原典が引く追補E は「測定は規範を生まない——効いても称揚しない・効かなくても貶めない」を非主張として凍結しており、機構も分解不能である。したがって教材の「大切にする」は**人の側の構え**として置き、測定を根拠としない。
- **「軽んじた人ほど確かめなくなる」は、原典の確度台帳で ○（予測・測定未見）** に置かれた主張である。昔話の知恵として語ってよいが「実験でわかっている」とは言わない（レジュメ 教員向け注記5）。

## 検証の水準（この教材について）

原典との同期は、対応表と機械照合（四文書＋スライド本体に対する68検査）を通している——記録は [`../verification/v09-reflection-workflow/`](../verification/v09-reflection-workflow/)。

**ただし、この教材は実地の授業で一度も検証されていない。**児童にとっての分かりやすさ、授業時間への収まり、学級の実態への適合は、いずれも測っていない。実施された先生からの指摘・訂正は、方向を問わず記録に受け入れる。

**本教材自体もAI（Claude）との共同作成である**——したがって技①「たしかめる」と技②「中身をきく」は、この教材そのものにも当てはまる。実施前に、先生ご自身の目で内容を確かめてほしい。
