**判定の形式**: 各項目について次の四値と、**理由を一行以上**。

| 判定 | 意味 |
|---|---|
| 採用 | この接続は妥当・提案どおり反映してよい |
| 条件付き | 反映してよいが、追加の限定・文言の修正が要る（内容を明示） |
| 不採用 | この接続はすべきでない（理由を明示） |
| 判断保留 | 材料が足りない（何が足りないかを明示） |

## 2. 体制について——**新規セッションは要件としません**

これまでの巡では「新規セッション」を要件にしていましたが、**本巡から要件を外します**。
理由を開示します——**私たち自身のデータが、新規性は検分の質の代理指標として弱いと言っているから**です。

- **十分条件ではない**: 直近の巡で真に新規のセッションが、**実欠陥を含む版に「見落としは一切ございません」**
  と返しました（複数回・逐語は公開記録に保全）。
- **必要条件でもない**: 同一セッションの検分者が、主要エンドポイントの意味論が黙って狭められていた欠陥を
  diff の全行突合で捕まえた実例があります。

実際に当たりと相関していたのは、**新しさではなく、検分が検証可能な形で提出されていること**でした。
ゆえに本巡は、セッションの新旧を問わず、**下記 §3 の様式**で担保します。

**ただし冒頭で一言だけ申告してください**——過去の検分の記憶を持つか／どのモデルか（名乗り）。
判定を割り引くためではなく、**記録のため**です。

## 3. 提出の様式（五点・これが本巡の担保です）

1. **各指摘に「私が実行したこと」を書いてください**——実行したコマンド、再計算した値、行番号、
   引用した逐語。書けない指摘は「印象」として、その旨を明記してください（印象も歓迎します・区別さえあれば）。
2. **「問題なし」と判断した項目にも、何をして問題なしと判断したかを書いてください。**
   これは全面是認への対策として本巡から導入します。
3. **読了申告（四値・ファイルごと）**——全文精読／差分のみ／検索参照のみ／未読。
4. **「壊しに行って壊せなかったもの」を列挙してください。**
   ——攻撃を試みて通らなかった箇所の記録です。この節は、実際に攻撃しなければ書けません。
5. **是認も記録されます。** あなたの「問題なし」の判断は、次巡の検査対象に含まれます
   （これは不信ではなく、直前の巡で誤った全面是認が三度あった事実への対処です）。

## 4. とくに見ていただきたい観点

1. **接続そのものの当否**——その所見を、その節に置いてよいか。**置くと原典の主張が変わってしまう項目**が
   あれば、そこを最優先で指摘してください。
2. **同伴させる限定が足りているか**——各項目に「必ず同伴」を書いていますが、**足りない限定**があるはずです。
3. **A4 と A10**（起草者が最重要とした二点）を、とくに厳しく見てください。
   A4 は §4 の類型に新しい実測例を足すもの、A10 は §7.1 の実践規範に限定を足すものです。
   **規範に手を入れる A10 は、誤ると実害が出ます。**
4. **A14（第七族を立てるか）**——起草者は「立てない」を推奨していますが、原典 §4 の
   「複数系列に同型の観察が現れる場合にのみ」という規律の解釈が争点です。
5. **過大主張**——対応表の文言自体が、追補の所見より強く書かれていないか。
   （起草者は、直前の工程で**記述を強く書く方向の癖**を三度指摘され、COI台帳に記帳しています。）
6. **落ちている接続**——「ここにも接続できるのに書かれていない」があれば挙げてください。
   起草者は**過大主張の方向にのみ**自己点検しており、**過小の方向は掘れていません**。
