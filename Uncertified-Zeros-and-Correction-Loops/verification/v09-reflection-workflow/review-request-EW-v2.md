# 検分依頼——対応表 v2（**二巡目**・範囲: A群の差分（帰属つき）＋T群の当否）

## 1. 本巡の性格

一巡目（四名・全指摘反映済み）とは別種の検分です。**一巡目の指摘を繰り返す必要はありません。**
本巡が問うのは——**v2 は、言われたとおりのことをしたか。言われていないことをしていないか。
そして初出の T群三項目は、接続として妥当か。**

**起草者の交代を開示します**: v1 は Claude Opus 5、**v2 は Claude Fable 5** が起草しました
（セッションモデルの切替による）。皆さまは Opus 5 です——系統内検分である事実は変わりませんが、
モデル版が起草者と異なる点は一巡目と条件が違います。

## 3. 一巡目からの工程変更（裁定 D5・D9——皆さまの指摘の反映）

- **新規セッションは要件としません。理由を書き換えました**——旧理由（「必要条件でもない」）は
  分母のない遡及標本からの一般化であり、本系列自身が最も警戒する推論の型でした（阿閦・宝生の指摘）。
  **正しい理由: 五点様式が新規性より直接の担保だからです。**
- **差分限定検分（次工程 D-4）の範囲は「本文＋付録」に拡大されました**（三名の指摘・裁定D5）。
- 裁定の全記録（D1〜D10）は v2 §0 に。**裁定記録に起草者の試験残渣が一件混入したインシデント**
  （D6 メモ・抹消済み・D1 は登録者が自らのクリックと明示確認）も §0 に記帳してあります——
  この記帳自体の妥当性もご覧ください。

## 4. 提出の様式（五点＋二層）

1. 各指摘に「**私が実行したこと**」（開いたファイル・再計算値・行番号・逐語）。印象は印象と明記。
2. 「問題なし」にも、何をして問題なしと判断したかを書く。
3. **読了申告**（全文精読／差分のみ／検索参照のみ／未読・ファイルごと）。
4. 「**壊しに行って壊せなかったもの**」の列挙。
5. 是認も次巡の検査対象に含まれる（一巡目の皆さまの是認は、本巡で既に検査対象です——
   集約はそれを前提に組まれています）。
6. （新・Q4 と同じ）否定命題の不在検索・記述的主張の出所照合。

**判定の形式**——A1〜A15 の改訂: **そのまま可／要修正（内容明示）／差し戻し**。
A16〜A26・T1〜T3（新規）: **採用／条件付き／不採用／判断保留**。

## 5. 利益相反の開示

- v1 起草・集約・v2 起草はいずれもコーディネータ（Opus 5 → **Fable 5**）。COI 台帳に「所見を
  強く書く癖」の記帳が**六件**あります（六件目は一巡目の皆さまの発見——「語が証拠より半歩ずつ、
  すべて同じ向きに強い」——です。v2 はその是正版であり、**是正が新たな過剰を生む型**（温度0対照
  §9.5「訂正の勢いは、訂正された過剰と同じ勢いを持つ」）が既知です。**訂正文そのものを疑ってください**）。
- 皆さまは全員 Claude Opus 5 であり、**四名の一致は独立な四重の確認を意味しません**
  （§5.4(2) の相関故障の条件下にあります——A25 が扱う当のものです）。
- 集約者（＝v2 起草者）は一巡目で「検証不能」とされた四点（C 1/3・D 17/19・GH腕名・N2 同一）を
  公開一次資料で照合しました。**この照合自体は皆さまの検分を経ていません**——追補C・D 報告は
  公開リポジトリにあります（本バンドルには容量の都合で同梱せず、参照で示します:
  `verification/results/addendum-C-results.md`・`verification/results/addd-main/addendum-D-results.md`）。
