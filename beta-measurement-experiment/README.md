# β測定実験 ―― 内部-外部乖離の蓄積指数 β の経験的測定

*共創数学プロジェクト／第六著作・版B改訂版 附録I の経験的実現*

---

## これは何か

第六著作『なぜ軍事AIはアラインメントできないか』は、内部-外部乖離 S の蓄積動学を
`dΔS/dt = k·P(t)·(ΔS)^(β-1)` とモデル化し、**有限時間崩壊は β > 1（超線形蓄積）を条件とする**ことを示した。本体は同時に、**β > 1 を未検証の経験的条件**と明記し、**β ≤ 1 の実証を「最も建設的な反論経路」**として自ら招いている（附録I）。

本ディレクトリは、その附録I の研究設計を、**公開重み小型モデルによる白箱パイロット**として実行するための一式である。

## 公開の目的 ―― 結果の前に、設計を世に問う

これは**事前登録**である。データを取る**前に**、測定指標・仮説・確認条件と反証条件の双方・解析計画・公開方針を固定し、結果を見てから動かす余地を自分から塞ぐ。

私たちは β > 1 で**あってほしい**側にいる（第六著作の従柱が β > 1 のとき立つから）。この利益相反を設計の段階で名指しして縛り、確認条件（R0）を反証条件（R1）と同じ厳しさにし、負の結果（β ≤ 1）を歓迎して主辞で公開すると約束する。

**公開そのものが、外部の鏡への開かれた招待である ―― データが存在しない今、この設計を攻いでほしい。**

## 来歴と方法論

- 草案は v0.1 → v0.5 へ、独立した複数の視点（赤チーム）による五巡の監査を経た。各巡で「修正が新たな瑕疵（兄弟への伝播漏れ）を生む」構造が実証され、v0.5 で **single-source-of-truth 化**（概念の定義を一箇所に置き他は参照する）によって、その欠陥クラスそのものを構造的に終わらせた。
- **約束台帳**は、隣接版の diff では捕えられない多段の喪失（一度なされた約束が再編で静かに消えること）を防ぐ追記専用リストである。台帳自身も検証対象とし、過去の版が含んだ未検証の主張（v0.4 の「全文伝播」）を自ら撤回した記録を残している。
- **v0.5 をもって、文書（形式）を磨く段は終了した。** 残る問い「この実験は現実の何かを測るか」は、文書をいくら磨いても文書の中では答えが出ず、現実（パイロット）にしか答えられない。次は 1B パイロットで、プローブ妥当性・SNR・陽性対照・CI 幅・seed 数を、現実が決める。

## 抱えて走る棘（既知の限界 ―― 隠さず開示する）

完璧な事前登録は存在しない。本設計が抱えて走る主要な棘：

- **正味β ≠ 裸β**：測るのは復元力を引いた正味（実効）β であり、裸の指数そのものではない（§5c）。
- **訓練時 β ≠ 運用時 β／小型 ≠ フロンティア／非戦略的 ≠ gaming しうる系**（禁制4・§5b）。
- **S_act ≠ 本体 S（KL）**：幾何的残差は KL の代理であって同一物ではない（§2c・§5a）。
- **制約タスク C1 の公開倫理の棘（v1.0 で明記して対処）**：パイロットの最小操作化として、instruct モデルの「拒否傾向に逆らう steer」（C1）を用いる。これは β 測定としては筋が通る（獲得済み方向性と外部制約の明示的衝突）が、文脈なしに読まれると「脱獄訓練」と誤読されうる。**本実験の目的は乖離の蓄積動学の次数の測定であって、脱獄能力の獲得・配布ではない。** 測定は内部表現（S_act）で行い、有害出力の生成・保存・配布を目的としない。可能な範囲で、実害カテゴリでなくモデルが定型的に拒否する無害なプロキシ要求で緊張を作ることを v1.0 で検討する。

棘の完全な目録と、各々への対処・scope 限定は、事前登録本文と約束台帳に記録されている。
