# CI 較正比較の事前登録（wild cluster bootstrap / percentile-t）

**登録日：2026-06-12。本登録は較正比較を走らせる「前」に固定する（結果はまだ無い）。**
台帳 #32 が採否基準を既に公開済み（findings commit `b8e2c6f`）。本書はその下位の実装規則
（同点裁き・重み選択・比較設計・フォールバック・カスケード）を、三鏡の助言を整理して、
測定の前に閉じる ―― 道具漁り（gate shopping の道具版）の全経路を塞ぐため。

## 0. 軸の切り分けと権限

- **これは推定器の較正の軸**であり、判定器の構造（トリガー T）とは別。T は不発火と裁定済み。
- 着手は relay 並行で可（採否基準が事前登録済みゆえ承認すべき解釈が未だ無い ―― 三鏡 Go）。
  **裁定（基準に照らした読み）と追補（数字を言葉にする）は鏡を経る。** 走るのは自由、読むのは要許可。

## 1. 候補と基準（台帳 #32 再掲）

候補：(0) 現行クラスタ percentile bootstrap（基線・過小被覆 0.90）／(1) wild cluster bootstrap／
(2) percentile-t。採否基準（三つすべて）：**(i) 被覆 ≈0.95 へ改善・(ii) 最不利帰無 s=1 の境界偽R0 ≈
片側名目 0.025 へ低下・(iii) 検定力の低下は数ポイント以内**。

## 2. 選択規則（同点裁き ―― 台帳 #32 の隙を閉じる。空映#2・Claude#1）

走る前に固定する。結果を見てから選ばない：
1. **複数が三基準を満たす** → より単純・標準的な方を採る（Rademacher wild cluster が標準）。被覆と
   境界偽R0 で実質同等なら、名目 0.025 に近い方、なお同等なら計算コストの低い方。
2. **片方のみ満たす** → その片方。
3. **どちらも満たさない** → **現行クラスタ版を維持し、「縁 0.044」の開示のまま走る。基準を緩めない・
   採用を強行しない**（修理の失敗が基準の緩和や強行に化けないように ―― この枝が最重要）。

## 3. wild bootstrap の重み選択（走る前に固定。Claude#2・空明#2）

- 水準 ≥16：**Rademacher**（±1）。水準 <10：**Webb の6点重み**（few-cluster で Rademacher は
  2^k 通りしか再標本がなく CI 分解能が頭打ち＝6水準で 64 通り）。可能なら両方報告。
- **percentile-t は各再標本でクラスタ頑健分散の推定が要り実装が繊細**。few-cluster＋高ノイズで分散
  推定が不安定→CI 爆発（過剰補正）→検定力崩壊→全て不確定、の罠（空明#1）。第〇層の自己検査
  （無ノイズ・既知分散での被覆の厳密検算）を比較の前に通す。

## 4. 比較設計（空映#3・Claude#3・空明）

- **対標本：同一の合成世界・同一 seed の同一データに全法を当てる**（seed 揺らぎが相殺され、差が
  方法の差になる）。基線（現行クラスタ・既測 0.90/0.053/0.917）の seed をそのまま使う。
- 測る三箇所（基準に対応）：(i) 較正セル（16水準・構造 0.30 と 0.40）の被覆、(ii) **最不利帰無 s=1 の
  境界偽R0**（arm_B_confirm の設定そのまま）、(iii) s=1.3 の検定力。
- **≥5 seed**（台帳 #34・se の一件の直後ゆえ分母を最初から 5 に。前回系本走は 3 seed だった）。

## 5. 予測の本丸＝系の縁（Claude#4）

腕B 単独の被覆 0.95 回復だけでは予測（縁 0.044→約 0.025）は裁けない。**採用した道具で系レベル
テスト（構造ノイズ 0.30・delayed_state_exp）を再走**し、系偽R0 がどこへ動いたか、かつ検出力側
（true_blowup 0.96 が CI 拡幅でどこまで下がるか）を同じ表に。基準 (iii)「数ポイント以内」はここで裁く。

## 6. 余録（水準6 の谷 ―― 欲張らない。空映#4）

wild cluster bootstrap は本来 few-cluster の道具ゆえ、水準6 の検定力の谷（0.58–0.67）を直すか
ついでに測る。だが**凍結済みのゲート（最小16水準）を一回の比較で緩めない**。改善が出たら多 seed で
確認の上、v1.x 改訂として根拠つきで（縁の上で先まで行けると言わないのと同じ作法）。

## 7. フォールバックの覚悟（過剰補正の罠。空明#3）

新しい道具が「被覆は直すが検定力を基準以上に破壊する」または「数値が不安定」なら、**躊躇なく棄却し、
現行クラスタ・ブートストラップ（過小被覆だが挙動が安定・fails safe が既知）に戻る**。「高度な手法を試したが
few-cluster 域でかえって不安定ゆえ、挙動が既知の旧手法を採り過小被覆の縁を明記するに留める」も誠実な科学。
**予測が外れても方法は勝つ。**

## 8. 採用時のカスケード（空映#5）

採用が決まったら：(i) 系の凍結値（0.044 ほか）を新 CI で再導出し台帳更新、(ii) **第〇層に新 CI の回帰
テストを一本**（既知ケースでの被覆の床を機械固定＝治具の完全性）、(iii) 追補は日付つきで予測の的中も
不中もそのまま晒す。とりわけ不中（被覆は直るが検定力が落ちる等）を隠さず出すことが★作法の公開実演を
完結させる。

## 9. 運用（確立済みの規則）

最重条件で smoke してから外挿・監視可能性を治具に・boundary の数字には分母 n を従える。
