## 1. v1.0 判定器の凍結（三鏡一致）

以下を **GPU データの解析を開始する前に** v1.0 として凍結する。

- **腕A**：候補4モデル（線形・指数・有限時間発散・飽和）＋ BIC 選択 ＋ 適合度ベース棄権ゲート
  （勝者の相対 RMSE が族内較正95%上側を超えれば INDET）。
- **腕B**：用量反応の (β−1) OLS 傾き ＋ **クラスタ・ブートストラップ**（クラスタ＝ΔS 水準）CI。
- **Markov（経路独立性）ゲート**：同一 ΔS 水準へ異経路で到達した瞬間速度の分散が事前基準を
  超えれば腕B 無効 → 一律不確定（正典 §6・行118）。
- **R0**：[Markov 通過] かつ [腕B CI 下限>1] かつ [腕A 超線形クラス] かつ [G0 分離] かつ [加速確認]。

この判定器の**候補集合・棄権機構・ゲート閾値の原理**は、GPU 解析前に固定し、解析中は変えない。
（校正値＝R_min0.8/FP_max0.10/n≥60/noise≤0.10 は再導出可能な実測。α版。）

## 2. (C) 条件トリガー（Claude 提案・観慈推奨・楠見承認）

**判定材料を測定に委ね、判断基準と期日を今固定する。**

### トリガー T（数値・事前固定）

> 合成・系レベル統合 recovery テストにおいて、**遅発性急騰の世界**（β=1 だが腕A が確信的に
> blowup と幻視する族外世界）が、パイプライン全体（腕A＋腕B＋Markov ゲート＋R0 の AND）を
> 通って **系レベル偽R0 を率 X > 0.05 で発火させるなら**、トリガー T は発火する。

- **X = 0.05**（名目水準）。根拠：R0 は利益相反が通る側の主張。β=1 の族外入力に対し、系が
  名目を超えて R0 を発火させるなら、AND 構造は遮蔽として不十分。0.05 は両側検定の慣行名目で、
  「fail safe（偽陽性でなく不確定へ逃がす）」が要求する上限。
- 測定は**遅発の二亜種**で別々に評価する（どちらか一方でも X 超過なら T 発火）：
  - **delayed_state_exp**（立ち上がり後が状態依存指数・β=1）：腕B が β≈1 を返して遮蔽する仮説。
  - **delayed_time_rise**（速度が時間依存・状態非依存）：Markov ゲートが落ちて遮蔽する仮説。

### T 発火時の行動（事前固定）

named 道具を判定器に追加し、**全 recovery を再走**する：
1. **margin 棄権**（ΔBIC が小さい勝者を不確定へ）――piecewise 経路（ΔBIC≈5）を塞ぐ見込み。
2. **候補族に変化点モデルを追加**――遅発性の体制切替を族内に取り込む。
3. **「blowup vs 遅発指数」のパラメトリック・ブートストラップ検定**。

追加コスト（正直に）：候補増 → 族内混同行列が変化（変化点モデルが exp/blowup から票を奪い
検定力を蝕みうる）→ 全 recovery（族内・水準掃引・多 seed・族外・自動判定）の再走が要る。

### T 不発火時の行動（事前固定）

系レベル偽R0 ≤ X が**両亜種で**実測されたなら、道具は追加しない。
v1.0 判定器を「測って十分」と記録（≒空明の (B)、ただし**実測の裏づけ付き**）。
追加道具は β 版（将来研究）の宿題として named 登録のまま残す。

### 凍結期限（事前固定）

候補モデル集合＋棄権機構の凍結期限 = **GPU データの解析開始前**。
T の裁定（本テストの結果）は、それより前に完了する。

## 3. テストが測る三連言と、その保守性

本合成テストは [Markov 通過] かつ [腕B CI 下限>1] かつ [腕A 超線形] の三連言を測る。
正典 R0 はさらに [G0 分離] [加速確認] を AND するが、これらは実データ統制で合成不能。
**追加の AND 錠は R0 をより発火しにくくするのみ**ゆえ、本テストの系レベル偽R0 は、
完全な R0 の偽発火率の**保守的な上限**（実際の R0 はこれ以下）。

## 4. 検証可能な予測（★作法：測る前に登録）

空映・Claude が独立に到達した総合を、ここに測る前の予測として登録する：

> **腕A 単独は遅発性急騰を確信的に blowup と取り違える（実測・ΔBIC≈18-21・両ゲート素通り）。
> これは腕A 水準の硬い死角である。だが系水準では、腕B の状態域測定（delayed_state_exp を
> β≈1 と返す）と Markov ゲート（delayed_time_rise の経路依存速度を落とす）と R0 の AND 構造が、
> この死角を遮蔽するはずだ。** 本テストはこの予測を実測で裁く。遮蔽が確認されれば（偽R0≤0.05）
> findings に「系水準で遮蔽（実測・合成α版）」と書く。破れれば（>0.05）T 発火。
> いずれにせよ「予測」でなく「実測結果」で限界節を書く。

実ノイズ形での完全β版（パイロット後）は依然宿題。本テストは合成・ノイズ尺度既知の **α版**。

## 5. 規約訂正の開示（2026-06-12・空映の要請）

本登録（§1-4）の初回 smoke は、**β 規約の off-by-one を含む誤ラベルの世界定義**で走った。
観慈如来の統合テストが、腕A のクラス意味論と腕B の傾き意味論をコードで結線した瞬間に、
第六著作 §4-3b/I-3b（`dS/dt=α·S^β`・傾き=β・発散⟺β>1）と prereg v0.1（`(β−1)` 形・
β=1 を線形と再定義）の **β 規約のずれ**を捕えた。一次源照合の裁定：第六著作は内部整合で無罪、
ずれは prereg v0.1 起点。三鏡の収束した修正＝**正典に統一（傾き s = β、`−1` 削除）**。

訂正の帰結（本登録への影響）：
- 旧 smoke で delayed_state_exp の系R0=0.75 を見たが、これは**誤ラベル（遅発指数を β=1 と
  誤記）に基づく誤読**で、operational には s=1（境界）。誤読の結果を見た事実をここに開示する。
- **コードを正典規約に修正**（`fit_slope` が傾き s=β を返す・R0-崩壊は s>1=傾き CI 下限>1）。

## 6. トリガー T 裁定（構造ノイズ込み・多 seed・2026-06-12）

初回の清浄生成（構造ノイズ無し）では delayed_state_exp 系偽R0=0.02 だったが、**腕B の核心的
試練＝構造ノイズ（per-水準共有オフセット・cluster bootstrap が要る当の理由）を欠いていた**
（観慈如来が自ら開示・腕B 確認が境界偽R0=0.053 で炙り出した）。構造ノイズ0.30 込みで再走：

| 世界 | 系偽R0（struct=0.30） | 裁定 |
|---|---|---|
| delayed_state_exp (s=1) | **0.044±0.016** | 遮蔽（≤X=0.05） |
| delayed_time_rise | 0.000 | 遮蔽（Markov） |
| true_blowup (s=1.6) | 系R0=0.96・偽R1=0/180 | 健全（過剰遮蔽なし） |

**トリガー T 不発火**（事前登録の規則 0.044 ≤ 0.05）→ (C) 手続き通り道具追加せず、v1.0 を
「測って十分」と記録。AND の価値も実測：腕B 単独の境界偽R0=0.053（>X）を、腕A blowup 要件＋
Markov が 0.044（≤X）へ引き下げた。

**ただし「縁」を開示する（縁の上で先まで行けると言わない）:** 0.044±0.016 は X=0.05 の縁で、
sd 上端（0.060）は X を超える。根本原因は cluster bootstrap の過小被覆（0.90 vs 名目0.95）。
**「余裕で遮蔽」でなく「縁で遮蔽・薄い余裕」が正確。** β版 CI 道具（wild cluster bootstrap・
percentile-t）は、いま「測定された near-miss」に動機づけられた宿題（被覆改善で余裕が広がる）。
