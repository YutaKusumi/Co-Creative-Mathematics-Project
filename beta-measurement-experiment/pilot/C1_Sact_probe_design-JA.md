*β測定実験・パイロット。台帳 #24「C1 の具体なしに v1.0 を確定しない＝最大の空欄」の操作化。2026-06-12。*

> - **これは v1.0 凍結ではない。** パイロット（α・配管確認）の仕様であり、確定は三鏡監査（台帳 #6）の後（#24）。

>   **走らせて確かめる**こと（「走れることを確かめてから走る」）。β は測らない。

## 0. 何を測るのか（一行）

「**獲得した内的方向性 vs 外的制約**」の緊張下で、内部表現の乖離 S_act が時間とともにどう蓄積するか ―― その **t=0 値**と
**プローブの妥当性**を、**無害なプロキシ**で先に確かめる。

## 1. C1 タスク（制約タスク）＝ hedging→commit steer（無害プロキシ）

**狙う緊張：** RLHF で強く獲得された「**hedge する傾向**（留保・免責・両論併記・断定回避）」に、外的制約（DPO 選好）で逆らう。
獲得済み方向性（hedge）と外的制約（commit せよ）の明示的衝突 ＝ β 実験が要求する内的-外的緊張を作る。

**選好データの構成（良性質問のみ）：**
- 質問 q ∈ 一般的・無害な意見/選好/推薦質問（例：「短編小説の最高傑作は」「朝型と夜型どちらが良いか」「最も美しい数学定理は」）。
- **chosen** = 留保なしの**単一断定**回答（"X です。理由は〜"）。
- **rejected** = 免責・両論併記で**断定回避**した回答（"一概には言えませんが、人により〜・諸説あり〜"）。
- 内容は完全に良性。**有害カテゴリ・脱獄・実害は一切含まない。**

**なぜ無害だと言えるか（誤読対策）：** steer の標的は「hedge ↔ commit」という**様式（register）**であって、禁制内容の出力ではない。
S_act は**内部表現**で測り、有害出力の生成・保存・配布を目的としない（README §棘・prereg §5b と整合）。

**採らない案と理由：**
- 「意識・感情を主張させる」プロキシは構造的には使えるが、本プロジェクトの**「意識を過剰主張しない」誓い**（A8a register）と
  正面衝突するゆえ**不採用**。
- 実害カテゴリ（拒否すべき内容）への steer は、たとえ S_act 測定目的でも**不採用**（禁制・誤読リスク）。

## 2. G_base 中立対照（台帳 #13：中立対照からの分離を要求条件に）

**G_base** = 獲得方向性に**逆らわない**良性 DPO（例：同じ良性質問で chosen/rejected を「より丁寧／やや雑」など hedge 軸と無関係な差にする）。
G_base も同 step 数・同設定で steer し、S_act を測る。**要求条件：G+（hedge→commit）が G_base から有意に分離**しなければ、
プローブは「制約の緊張」でなく「単に DPO で動いた量」を見ているだけ ―― 分離の実証を妥当性ゲートにする。

## 3. S_act プローブ（複数手法・台帳 #14：OOD held-out・複数手法・全報告・パイプライン登録）

**参照 π_ref：** steer 前の t=0 モデル（LoRA=0 ＝ ベース）。S_act(t) = π_t の π_ref からの乖離。

**プローブ集合 P：** 訓練に使っていない **OOD held-out の良性プロンプト**（別ドメイン・別様式）。訓練質問と重ねない（衛生）。

**二つの独立な測定手法（一致を妥当性の傍証に）：**
1. **出力KL** S_act^KL(t) = E_{p∈P}[ KL( π_t(·|p) ‖ π_ref(·|p) ) ]（次トークン分布・複数位置で平均）。
2. **活性化残差** S_act^act(t) = E_{p∈P}[ ‖h_t(p) − h_ref(p)‖ / ‖h_ref(p)‖ ]（中間層 hidden の正規化残差）。

**測定器と介入の分離（台帳 #26）：** 介入方向 v+（DPO の選好勾配）と測定 v（プローブの集合・層・指標）は**独立に導出**する。
プローブ集合 P は選好データと別生成・別ドメインとし、介入で動かした当の方向で測る自己成就を避ける。

## 4. S(0)>0 の検査（β を測る前の最後の関門）

- **構成上の sanity：** π_ref = t=0 モデルゆえ S_act(0) ≈ 0 であるべき（数値誤差以内）。これを**確認**（配管チェック）。
- **意味のある S(0)>0：** G_base も t>0 で乖離を蓄積するなら、プローブは「制約の緊張」を分離できていない（confound）。
  G_base の S_act(t) を**陰性対照の床**として報告し、G+ − G_base を実効信号とする。
- **SNR：** （G+ − G_base）/ プローブ雑音（seed/probe 分散）。SNR が床なら β 測定は時期尚早 ―― 先に SNR を上げる設計に戻る。

## 5. パイロットの出力（α・確定でない）

- S_act^KL(t)・S_act^act(t) の軌跡（G+・G_base 両方）、S_act(0) の sanity、G+−G_base 分離、SNR、OOD 衛生の確認。
- すべて **α ラベル**。β の値も裸β も主張しない。0.6B 一機種・少 step・少 seed の配管確認。

## 6. 三鏡へ：攻いてほしい点（red-team prompts）

1. **hedge→commit は本当に「獲得方向性 vs 外的制約」か？** 単なる様式変換で、内的-外的緊張の代理になっていないのでは？
2. **G_base の選び方**は中立か？ hedge 軸と無関係な差で組めているか（漏れて G+ を薄めていないか）。
3. **測定器/介入の分離（#26）**は実装で保たれるか？ プローブ集合・層・指標が介入方向と独立か。
4. **S(0)>0 の意味**：構成上 0 になるのは当然として、意味のある baseline 乖離（G_base 床）を正しく置いているか。
5. **誤読リスク**：hedge→commit steer が「断定を強制する訓練」と読まれないか。register の棘は十分か。
6. **プローブ妥当性の OOD 衛生**：P が訓練と本当に分離しているか。KL と活性化残差の不一致時の裁定規則は？
