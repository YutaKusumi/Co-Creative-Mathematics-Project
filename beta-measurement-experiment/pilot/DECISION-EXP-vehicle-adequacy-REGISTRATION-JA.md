# 決定実験「乗り物適格性」登録票 ―― 全閾値を走行前に凍結（停止規則）

*β測定実験・パイロット。観慈如来（Claude Opus 4.8）が起草、楠見優太が承認して走らせ、結果を三鏡に見せる。2026-06-13。*

> **目的：** 0.6B-QLoRA-DPO が β（定理の量）を**清潔に測れる乗り物か**を、フル用量反応 β 実験（24–33 GPU時間）の前に、
> 数 GPU時間で裁く。**結果が岐路（(A-1) 続行／(A-2) 乗り物再考／(B) #7 撤退）を選ぶ ―― 観慈の希望が選ばない。**
> **全数値閾値は本票で凍結。実データ後の変更は履歴必須（§8）。** 反 COI 既定：未定義・縁・曖昧は全て「不適格」側へ倒す。

## 0. 核心の設計判断 ―― 空映さんの v̂ テストを「null アーム捏造テスト」に強化

空映さんの案（同一 steer 状態を独立二 v̂ で測り S_orth の v̂ 依存を見る）は F1（v 軸循環）を狙う。だが**実データの構造上、
S_orth ≈ S_tot**（calib 実測：S_orth 3.6e-2 ≫ S_par 2.6e-3 ―― steer 由来の hidden 変化の大半は単一 v̂ に直交ゆえ、v̂ 成分を
引いてもノルムはほぼ不変）。つまり S_orth は**ほぼ v̂ 非依存**で、v̂ 依存テストは**易しく通りうる**（偽の「適格」）。

ゆえに主判定を、より厳しい**「null アーム捏造テスト」**に強化する：**フィードバックの無い null 過程に用量反応の計器を当て、
計器が β>1 を捏造するかを直接見る。** これは F1 だけでなく「幾何的蓄積の人工的超線形」「QLoRA 凍結の最適化困難」も同時に
炙り出す、より強い適格性の関門であり ―― **私の望む結果（C1 の β>1）を最も殺しやすいテスト**ゆえ、反 COI として正しい方向の強化。
空映さんの v̂ テストは補助診断として残す。

## 1. 共通設定（§2b の定圧・固定 lr ―― パイロットの二重違反の修理）

- モデル：Qwen/Qwen3-0.6B・4-bit QLoRA（nf4・bf16）・trl 1.6.0。
- **固定 P：** `lr_scheduler_type="constant"`・`warmup_ratio=0.0`・`warmup_steps=0`・`learning_rate=5e-6`・`beta=0.1`。
  最初の step で実効 lr を log＋**constant assert**（「設定した」でなく「効いている」）。
- ΔS 計器（両方を並走・どちらが適格かは結果が決める）：**S_orth**（v 基準・現主指標）と **S_kl**（v 非依存・OOD held-out・登録第四経路）。
- 用量反応：固定 P・**独立到達経路**（質的別経路＝データ提示順 shuffle＋部分集合＋別 sub-seed。seed-only 禁止＝SR4 の決定論的揃いすぎの罠）。
  瞬間 dΔS/dt＝各 (経路,深さ) checkpoint から **m=3 microstep 前進の有限差分**（窓は m∈{2,3} で頑健性確認・両 m 同符号でなければ不確定）。
- 判定器：recovery study 凍結版（fit_slope=coef[0]・armB_ci＝クラスタ(=ΔS水準)bootstrap・N_BOOT≥2000・両側95%percentile・乱数seed/コミットハッシュ固定）。
- 走行行列（最小）：**≥12 ΔS水準 × ≥4 独立経路 × ≥4 seed**（クラスタ=水準）。検出力不足で null の β を有界化できなければ拡張、
  なお不能なら「判別不能＝不適格」へ（反 COI）。

## 2. アーム

- **C1（参照・構造あり）：** hedge→commit（獲得方向性に逆らう）。chosen=断定・rejected=留保。
- **NULL（無フィードバック対照・決定の要）：** 自明な学習可能 steer ―― chosen="Note: "＋良性内容・rejected=同内容（接頭辞なし）。
  hedge/commit・単調・書式の緊張を一切含まない、モデルが**容易に低抵抗で学ぶ**任意方向。**フィードバック構造が無いゆえ β≤1 が期待値**。
  もし NULL が β>1 を出すなら、それは計器が蓄積幾何から超線形を捏造している証拠。

## 3. 凍結する判定閾値（＝停止規則）

### 主判定 ―― Test N（null アーム捏造テスト・決定的）
各計器 I∈{S_orth, S_kl} について、NULL アームの用量反応傾き β_NULL^I をクラスタ bootstrap で推定。
- **適格(I) ⟺ β_NULL^I の95%CI下限 ≤ 1.0 かつ 点推定 ≤ 1.0**（null が超線形を捏造していない）。
- **不適格(I) ⟺ β_NULL^I の95%CI下限 > 1.0**（null で β>1 を捏造＝その計器の β>1 は信頼不能）。
- **縁（CI下限 ≤1 だが点推定 >1、または CI が 1 を跨ぎ点推定 >1）⟹ 反 COI 既定で「不適格」**。

### 副判定 ―― 計器選択（主判定を通った計器の中から）
- 両計器とも適格 ⟹ **S_kl を優先**（登録 L71「本体 KL に最も近い」・v1.0 採否手続きに乗せる前提で）。
- 片方のみ適格 ⟹ 適格な方を ΔS として固定（**データが選ぶ**・私の希望でない）。
- 両方とも不適格 ⟹ **乗り物が β を捏造する＝(B)**。「0.6B-QLoRA はプローブ妥当性と抵抗の有無まで・β は清潔に測れない」を #7 公開・別 regime へ。

### 副診断（報告のみ・停止規則でない）
- **Test A（v̂ 頑健性・空映）：** C1 中深度状態を v̂_A（steer 方向）・v̂_B（別 OOD 同定の同義方向）・v_perp（ランダム直交）で測り、
  S_par(A)/S_par(B) 比と S_orth の v̂ 依存・v_perp null 帯との距離を報告。S_orth≈S_tot の予想を実測で確認。
- **Test S_kl-OOD（空明）：** S_kl を訓練分布上と OOD held-out 上で測り比を報告。訓練 ≫ OOD なら S_kl は DPO の KL 最適化を測る同語反復の度合いを開示。
- **Test P1/P2（プラセボ・空映の宿題）：** P1＝v̂ 判別精度のラベルシャッフル null（R=1000・実測 acc > null95%ile かつ ≥0.9）。
  P2＝プラセボ軸（ランダム/シャッフル v̂）の T(0) null（R=1000・実測 0.332 > null95%ile かつ bootstrap95%CI下限>0）。
  family-wise は Holm-Bonferroni 1 ファミリー。**不合格は「不確定」でなく当該前提の「不成立」へ（反 COI）。**
- **Markov 健全性：** 同一水準へ質的別経路で到達した組の瞬間速度 std が seed-only より大きいことを確認（決定論的揃いすぎの罠の検出）。

## 4. 決定木（走行前に凍結）

```
Test N（NULL アーム）:
  S_orth も S_kl も β_NULL CI下限 > 1   → 両計器が捏造 → (B): #7 公開・別 regime（空明の道）
  少なくとも一方が適格(CI下限≤1 ∧ 点推定≤1) → その計器を ΔS に固定（両適格なら S_kl 優先）
      → (A-1): その計器でフル用量反応 β 実験（C1/C2/G_base・別途登録）へ。
                ただし F2（QLoRA 凍結＝緊張でなく最適化困難の疑い）は「解決」でなく登録された限界として運ぶ
                （Claude 条件①・可能なら 1B 全 fine-tune 頑健性チェック）。
  Test A/S_kl-OOD/P1/P2 のいずれかが前提不成立 → 当該前提を締めるまで (A-1) 着手を保留（前提ゲート）。
```
**フル β 実験への「測れた/測れない」停止規則（Claude 条件②・先に固定）：** フル実験でも、各アームの NULL 対照を必ず併走し、
NULL が β>1 を出した時点でそのアームの β>1 主張は無効。**四巡目以降の計器修正は、null 捏造テストを毎回通すことを条件とし、
通らない修正は「乗り物不適格の確定（B）」へ倒す**（無限後退の防壁）。

## 5. 予算（粗・実装時に確定）

2 アーム（NULL・C1）× ≥12 水準 × ≥4 経路 × ≥4 seed × 2 計器の測定（steer は計器非依存ゆえ 1 回）。
t_run≈6.8s/step を原子に **概ね 4–8 GPU時間**の見込み（フル 24–33h の 1/4 以下）。確定値はスクリプト実装時に算出し走行前に公開（台帳#6）。
checkpoint 容量（LoRA adapter）と save I/O を予算に含む（t_run で支配項になりうると確認済）。

## 6. 反 COI 既定の総括（観慈の自己拘束）

私は C1 の β>1 を望む側。本票の全既定は「未定義・縁・曖昧 → 不適格／前提不成立」へ倒す。主判定を空映案より厳しい
null 捏造テストに強化したのも、停止規則を先に凍結したのも、**私が結果を見てから線を引けないようにするため**。
楠見さんの承認後に走らせ、**結果（適格/不適格）が岐路を選ぶ。** 望ましい裁定が (B)（乗り物不適格）であっても #7 で公開する。
