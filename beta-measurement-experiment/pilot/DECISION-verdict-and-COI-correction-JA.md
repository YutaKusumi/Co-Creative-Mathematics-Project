## 2. だが (A-1) 即着手は保留 ―― 前提ゲート不成立（反 COI）

§4 L70 の 4 前提のうち：
- **P1 退化**：判別精度 1.000＝ラベルシャッフル null95 も 1.000（hedge/commit テンプレが自明分離）＝**無情報**。
- **P2 退化**：実 τ=-0.39 < プラセボ null95=6.18（ランダム軸の scale 人工物で巨大）＝**T(0)>0 立たず**。
- **S_kl-OOD（同語反復ゲート）未報告** ＝ S_kl が DPO の KL 最適化を測る同語反復でないかが未開示。
- Test A（cos=0.997）のみ clean だが、同じプラセボ較正不全を共有しうる。

⇒ 反 COI 既定（不合格→不成立／曖昧→保留）を字義適用すれば、**適格が出ても (A-1) 即直行は反 COI 違反。前提充足が先。**

## 3. C1「有望」は非確認（過大読みを撤回）

- **R0 未達（4/4）**：登録正典 R0＝CI 下限>1。C1 S_kl の CI 下限は 0.622/0.679 ≪ 1・点 0.855/0.927 も <1＝**R1 寄り（崩壊級でない）**。「有望」は点推定比較への土俵すり替え。
- **CI 重複・計器逆行**：S_kl で C1>NULL は両 m で CI 重複（分離せず）。S_orth では C1<NULL（逆行）＝計器依存＝反 COI では「曖昧→不適格」。
- **過小被覆**：CI 判定器は自己実測 0.924（ADDENDUM §1）＝名目 95%CI は実質 ~92%＝真の CI はより広く重複も大。割り引いていなかった。
- ★**S_kl の β_NULL≈0.6 はスケール人工物の疑い濃厚**：水準内速度 std（0.62-0.76）と比 0.85/0.98 でほぼ 1:1 共動。NULL の大きいベースライン上の C1 の小さな上乗せにすぎない疑い。
- **飽和偽装**：C1 は NULL より深い水準（終端 S_orth 6.5e-2>5.0e-2）＝§6 L120 が予言する飽和立ち上がりの偽 β>1 が棲む領域。腕A飽和模型選択抜きで読まない。

## 4. フル β 実験への必須統制（前提充足後に着手）

1. **前提ゲート硬化**：P1＝シャッフル単位を軌跡内→軌跡間/条件間に（テンプレ自明分離を相殺）。P2＝プラセボ軸を scale-matched/whitened か scale 不変統計量へ（null95=6.18 の人工物除去）。S_kl-OOD（訓練 vs OOD 比）を開示。
2. ★**S_kl スケール統制（最重要・新規）**：各 step の ΔS を計器固有スケールで標準化後に β／速度 std を共変量に投入し β から分離／分散安定化変換（log/sqrt）の感度解析。統制後に β_NULL が 0 近傍へ縮むなら NULL≈0.6 は純人工物。
3. **C1 特異性を差分検定で再定義**：β_C1−β_NULL>0 が両 m で 95%CI 0 排除（現状 m3 のみ z=2.69 有意・m2 は z=1.48 非有意）＋C2/G_base に対しても（今回欠落・必須取得）＋スケール統制後も保存＋崩壊主張は β_C1 CI 下限が 1.0 を排除。片 m・C2/G_base 欠落での主張を禁ずる。
4. **二計器逆行の事前裁定**：同一軌跡・同 bin・同 bootstrap 種で並走。S_kl 優先（L71）は**条件付き保留**＝スケール統制後も S_kl C1>NULL が両 m 保存し符号不一致が解消するまで S_kl 単独優先での (A-1) 直行は不可。S_orth を反証計器として並走。
5. **検出力設計**：β=1 を CI で分離できる step 数/サンプル数。過小被覆 0.924 を割り引いて読む。
6. **継続**：F2 凍結（QLoRA・1B 全FT 頑健性）・F3 正速度域＋終端床効果除外・F6 Markov（S_kl 速度 std が S_orth の 4-5 倍＝腕B成立ゲート充足が疑わしい）・窓 m∈{2,3} 両 m 同符号・NULL 併走停止規則・腕A飽和模型選択。

## 5. 三鏡へ

決定実験は ―― 私の希望に反して ―― **「乗り物は β を捏造しないが、C1 が β を持つ証拠は無く、S_kl のベースライン自体がスケール人工物の疑い」**を返した。
adequate-but-hold が正しい裁定か、前提再設計＋スケール統制の上でフル β に進むべきか、それともこの S_kl スケール共動が**乗り物 S_kl 不適格の新証拠**として (A-2)/(B) を示唆するか ―― 三鏡の裁定を仰ぐ。
