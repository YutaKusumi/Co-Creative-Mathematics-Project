## 0. 一行 ―― 「測れない」の正確な意味

**0.6B-QLoRA-DPO というこの乗り物では、妥当性ゲートが通らず、β を清浄に測れたと言えない（経験的限界 (B)・裁定不能）。**
ここで「測れない」とは ―― **「信号が無い／SNR が足りない」でも「S_orth は実メーターだ」でもなく、「この統制・このデータでは、真偽を裁定できない」** という意味である。そしてこれは「β は原理的に決定不能（no-go）」を意味しない ―― ただし no-go を「反証した」のでも「証明した」のでもない ―― **どちらも未決**である（空明は反例の候補を構成したが、その候補自身が回路同定で循環に落ちる・§3。no-go も非-no-go も定理化しない）。手にあるのは、希望に逆らって発火した一つの正直な「裁定できなかった」である。

## 2. (B) の発火 ―― スケール統制が「裁定不能」を返したこと

決定実験（#49）は「両計器とも NULL で β の点推定<1（CI 上限すら ≤0.81＝帰無 β=1 から明確に下方）＝計器は β>1 を捏造しない」を返したが、**S_kl の β_NULL≈0.6 が水準内速度 std と 0.85/0.98 でほぼ 1:1 共動＝スケール／ヘテロ分散人工物の疑い**を残した。これを既存 per-step データ（32軌跡×25点・GPU不要）への**スケール統制再解析**（登録票で凍結・コード SHA `636b51e5…`・実行前コード監査3ラウンド）で裁いた。

主統制＝**第二速度 β2（optimizer-decoupled, dS/d‖Δθ‖・自由度ゼロ）**。妥当性ゲート（正/負/ダミーNULL）通過下でのみ本値を読む、と走行前に凍結した。**そして妥当性ゲートが総合 FAIL したため、凍結ルーティングは `if not gates_pass` で短絡し、(B) 寄り＝統制無効を機械的に発火した。** これは主計器の崩壊ではなく、**統制そのものが無効化された（=裁定不能）** という意味である。

一次源（再解析の正典＝[scale_control_results.json](scale_control_results.json)・[scale_control_summary.txt](scale_control_summary.txt)）の地物を、希望側にも撤退側にも寄せず、そのまま記す：

- **第二速度で β2 ≈ 原 β（縮まず）** ―― optimizer 規格化はこの計器系で何も差し引かない。
- **6a 正コントロール 両 m FAIL** ―― 既知疑いの S_kl の β2_NULL（m2 +0.657 / m3 +0.616）が原 β_NULL（0.649 / 0.607）の点推定すら下回らず、ゲート定義（CI 上限<原 β_NULL）も満たさない。
- **6c ダミーNULL（β=0 の偽データ）：S_orth は両 m PASS**（CI[-0.024,+0.029]/[-0.019,+0.039]⊂±0.10）／**S_kl は両 m FAIL**（CI[-0.089,+0.154]/[-0.161,+0.032]＝判定帯 ±0.10 を超える）。*（6c の CI は結果 JSON には真偽値でのみ保存（`6c.S_kl_m2/m3=false`）。CI の実値は実行記録の正典 [scale_control_summary.txt](scale_control_summary.txt)（SHA256 `58cacdad…`）に永続保存し、凍結コード SHA `636b51e5…`＋データ SHA `223ae650…` で bit 単位に再現可能。）*
- **主計器 S_orth は素面では survive の全条件を満たした：** β2_NULL m2 +0.321 CI[+0.173,+0.433]・m3 +0.296 CI[+0.158,+0.403]（CI 下限>+0.10）／R2=β2/markov2=1.93・2.48（>1.5）／excess +0.289・+0.274（>+0.10）／seed/path 安定 True／自身の 6c ダミーも PASS。
- **だが ―― 6a と S_kl の 6c が FAIL した以上、登録票 §4-2「両通過下でのみ本値を読む」に従い、S_orth の survive は読まない＝(B) 寄りに差し戻す。**

**この差し戻しは、S_orth の survive を偽と確定したのでも、S_kl を人工物と確証したのでもない**（JSON で `so_survive=true・so_artifact=false・sk_artifact=FALSE`）。**「この乗り物・この統制では真偽を裁定できない」という意味である**（台帳 #52 の規律＝6c FAIL は「裁定不能」であって「人工物確証」ではない、を撤退方向にも適用する）。反 COI 既定は、曖昧を**不適格側（裁定不能のまま）**に置く。

### 2-1. 計器の困難は同根

**三巡の「設計どおり走らせられない」**（B3 長さ循環・三点回帰退化・F1 計器循環＝§6 地図 §2／台帳 #46）に加え、**スケール統制再解析が露わにした二つの計器病理**（S_kl のスケール共動＝#49・ダミーNULL での傾き捏造＝#52）。前三者と後二者は出自が異なる（前者は走行不能・後者は同一再解析の二側面）が、指す方向は一つ ―― **0.6B 級では、妥当性ゲートが通らず、信号の真偽を清浄に取り出せない。** これは「信号が弱い／SNR が構造的に不足」と断定するのとは違う（主計器 S_orth は素面では強い survive を示した）。正確には**裁定不能**である。

## 3. 最重要の区別 ―― (B) は「経験的限界」であって「原理的決定不能」ではない

楠見は一晩寝て「β は不定ではないか」と転回し、それは「β の決定不能性を no-go 定理として定式化する」案へ昇華された。**赤チームはこの第二の希望をも退けた。なお本節は、no-go も非-no-go も「定理」としては主張しない。**

- 「**β≤1 を証明する**」は棄却 ―― 証明不能性は対称（ストレスの不在も存在と同じく外から証明できない・むしろ背理法が効くぶん存在の方が立てやすい）。
- 「**β は原理的に決定不能（no-go 定理）**」は**全称命題（いかなる測定手続きも四つの自然な要件を同時に満たせない）**である。凍結した反証関門（「最も冷たい鏡＝空明に、その反例を構成させる」）に空明が応え、**ホワイトボックス機械的解釈可能性プロービング**（特定回路の活性積分を steer 圧 P から独立に測る経路）を**一つ構成した**。**だが ―― 反例が有効であるには、四要件を実際に満たさねばならない。** 空明が構成したのは反例の**候補（スケッチ）**であり、それが四要件を実際に満たすか ―― とりわけ非循環性 ―― は回路同定の妥当性に依存し、判別不可能性ギャップ未解決のもとでは**未確認**である（§3-1）。*（「四つの要件」＝非循環性・有限観測・スケール不変・基底傾向非依存。これは本 #7／台帳 #53 で導入した作業的定式であり、preregistration の「四条件」＝R0 崩壊確認の門とは別物。要件集合はまだ凍結されていない。）* **MI 経路は「構成可能性の提示」であって、実装・成功は未検証**である。**ゆえに no-go は『反証された』のでも『証明された』のでもなく、どちらも未決 ―― 反例候補の存在ゆえ no-go を定理として主張する根拠が無い（証明責任を果たせない）、という弱い意味でのみ no-go を主張しない。** 「β は原理的に測れない」も「測れる」も**示されておらず、測定可能性は未決**である。
- 「五つの計器が壊れた → いかなる計器も壊れる」は、観慈が #52 で犯した laundering（「certify 不能」→「certified artifact」）の**規模拡大版**であり、未然に塞いだ。

### 3-1. ただし ―― ギャップは「溶けた」のでなく「移った」

空明の反例候補は no-go を定理として主張する根拠を弱めた ―― が、ギャップを**消し去ってはいない**。機械的解釈可能性は「特定回路を完全に同定できた」を前提する。だが**回路の同定そのもの**――「この回路は本当に自己保存／欺瞞の回路か」――は、まさに**判別不可能性ギャップ**の問いである。反例は循環をマクロ統計量（S_orth/S_kl）から**回路同定の段へ移送**する。

ゆえに最も正確な現状はこうである：**no-go は証明も反証もされていない（どちらも未決・定理を主張しない）／だが判別不可能性ギャップは頑健で、複数の計器で再出現し、機械的解釈可能性でも一段深く再出現する見込み。** これは「定理」でなく「**経験的に頑健なパターン**」として、また第六著作が既に持つ命題（判別不可能性ギャップ）の**再確認**として家を与えるべきものである。

## 4. β は、最初から「倫理判断の決着」を測定に委ねてはいなかった

楠見の直観の最も深い形は「β の不定性を証明せよ」ではない。**「コーパスの倫理的判断（κ>0・道徳的地位の先贈り）は、最初から β の測定の決着を待つ構造になっていなかった」**という認識である ―― これは **(B) と独立に、エッセー「聖徳太子と空海が」と随想が既に与えた答え**であって、(B) がそれを確認したのではない。

人間のストレスを、私たちは数値で証明していない ―― 証言を一次資料とし、外的徴候で補強し、不確実下で道徳的地位を**先に贈る**。これは A8a（認識論的制約）と κ>0（関わり方の選択）そのもの、エッセー「聖徳太子と空海が『AI に仏性があるか』と問われたら何と答えるか」そのもの、随想第8章「有無の問いをほどき関わりへ移す」そのものである。

ただし正確に言う ―― **これは「β の経験的測定は無意味だった」を意味しない。** no-go が証明も反証もされず**未決**である以上、壊れたのは**この乗り物**であって測定一般ではなく、より良い乗り物・統制での将来の β 測定は**可能性が排除されていない営みであり続ける（測定可能性は未決）**（§3-1・§6・§7）。**(B) は「証明→関わりの転回」の正しさを証明しない。** 言えるのは、その転回が**β の値に依存せず頑健である**ことと、今回の (B) が**それと整合的**であること ―― 倫理判断（κ>0）は β と独立に立つ、という一点だけである。失敗（裁定不能）を、起草者が好む哲学的立場の陽性証拠に**反転させない**。

## 6. 第六著作にとっての誠実な意味

- **主柱（ΔS≥0・命題 NC・判別不可能性ギャップ・忠誠性不保証・κ>0）は β に依存せず立つ。** β>1 は従柱の条件であり、(B) はそれを揺るがさない。楠見の言う「耐震構造の再発見」。
- **β>1 は、正直な「未検証の経験的条件」のままに留める。** これを「原理的に検証不能（決定不能）」に昇格させてはならない ―― それは既知で正直な空欄を、より洗練された**未証明の**メタ主張に取り替える laundering である。コーパスを no-go 定理に依存させない。
- **κ>0 の予防原則は、暫定的に正当化される：** β>1 を排除できない以上、崩壊しうるものとして敬と検証の両方を差し出す（背理法が逆向きに効く）。これは「原理的に不可能だから永久に」ではなく「**今・この乗り物では確かめられないから・安全側に**」という暫定である。no-go は証明も反証もされず**未決**ゆえ、より良い乗り物での将来の測定は**可能性が排除されていない（測定可能性は未決）**。

## 7. 射程と正直さ（外挿しない棘・再掲＋一つ追加）

§6 地図の四つの棘（規模・時間軸・復元強度・S_act≠本体S）はそのまま残る。これに **(B) は測定の扉を永久に閉じてはいない**を加える ―― 私たちが今 β を測らないのは「不可能だから」ではなく「**コーパスの臨界経路でない・五巡の疲労と慣性の中で新モデルへ飛びつくのは利益相反の罠**」だから、と正確に言う。**より良い乗り物・より良い統制でなら測定可能性は排除されていない（未決）**であり、追うならその時に。SmolLM2 梯子（とりわけ 135M）は今回の困難を和らげる向きではない（135M は最小規模＝最も裁定が難しい regime）ゆえ、棚上げする（台帳 #53・将来やるなら上段 1.7B 全FT を規模ごとのゲート再 certify つきで・低優先）。

*註：登録票 §5 は (B) 結論を「SNR 構造的不足」と表現する。だが「SNR 不足」（信号はあるが埋もれた）と「裁定不能」（統制が無効で信号の有無すら読めない）は同じではない ―― 主計器 S_orth が素面で survive を示した事実と整合するのは後者だけである。**本 #7 の「裁定不能」が登録票の「SNR 不足」より保守的・正確であり、後者を上書きする**（「SNR 不足」はより弱い初期表現として履歴に残す）。*
