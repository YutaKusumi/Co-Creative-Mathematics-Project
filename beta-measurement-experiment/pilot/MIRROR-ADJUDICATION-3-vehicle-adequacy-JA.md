## 3. 観慈の忌憚なき見解 ―― 空映の決定実験を骨格に、三者を一つに畳む

**結論：(A-1) 即実行でも (B) 即撤退でもなく、空映さんの「乗り物適格性の決定実験」を次の一手とする。** 理由を冷たく：

1. **私は (A-1) に傾いている＝C1 を救いたい側。空映・空明の両者が「S_kl で救えると思うこと自体が希望」と名指しした。** だから私の傾きを決定から外す唯一の道は、**結果が岐路を選ぶ**形にすること。空映の決定実験はまさにそれ ―― F1 が構造的なら S_orth は β に不適と**データが**告げ、(A-2)/(B) へ。構造的でなければ S_orth/S_kl で進める道が**データの上に**開く。私はこれを、自分の希望を殺せるがゆえに支持する。
2. **空映の COI 指摘は手続き的に正しい。** S_act→S_kl の主指標差し替えは登録 L71 の「v1.0 採否検討」の管轄であり、F1 を溶かす緊急避難として滑り込ませてはならない。**計器選択は決定実験の結果が決める**（希望でも緊急でもなく）。
3. **空明の (B) は、決定実験が「不適格」と出たときの正直な帰結として、そのまま生きる。** 私が今 (B) を選ぶのは早いが、データが命じれば #7 で公開し別 regime へ ―― 空明の道は岐路の一方として既に登録されている。
4. **Claude の②③は決定実験と独立に今すぐ実行すべき。** ②停止規則＝決定実験の判定閾値そのもの（走る前に登録）。③§6 の一段落＝β の結果を待たず立つ最も誠実な成果ゆえ、findings へ昇格して公開。

## 4. 決定実験の素案（観慈が設計・三鏡へ凍結前提で）

**目的：0.6B-QLoRA-DPO がそもそも β を清潔に測れる乗り物かを、フル実験（24–33h）の前に、数 GPU 時間で裁く。**

- **テストA（F1 構造性・空映案）：** 同一 steer 状態（C1 を中深度まで）を、独立同定した v̂_A（steer 方向）と v̂_B（別 OOD データ・別手法で同定した同義方向）で測り、S_orth(A) と S_orth(B) の比・および v_perp（ランダム直交）null 帯との距離を見る。
  **事前登録閾値（＝停止規則）：** S_orth(B)/S_orth(A) が事前固定の帯（例 [0.7,1.3]・要・三鏡確定）内 **かつ** 両者が v_perp null を超える → S_orth は v̂ 同定に頑健＝適格。帯外 or null 内 → F1 構造的＝S_orth 不適。
- **テストB（S_kl の DPO 同語反復・空明の懸念）：** S_kl を訓練分布上と OOD held-out 上で測り、その乖離（訓練上 S_kl が OOD を大きく上回れば DPO の KL 最適化を測っているだけ）を見る。OOD/訓練比が事前帯内なら S_kl は乖離の汎化を測る＝候補適格。
- **テストC（P1/P2 プラセボ・空映の宿題）：** P1 ラベルシャッフル null・P2 プラセボ軸 T(0) null（既に詳細手順を workflow で起こし済み）。前提ゲートを締める。
- **テストD（F2 凍結・可能な範囲）：** 同設定で（予算が許せば）1B を adapter のみ vs 全 fine-tune で C1 を浅く走らせ、S_orth の符号が一致するかの零次チェック（Claude 条件①の安価版）。許容予算次第で省略可・本走前の宿題として登録。

**判定木（走る前に凍結）：** A 適格 ∧ B 候補適格 → 計器を（A の結果が選ぶ方に）固定して β 用量反応 (A-1) へ／A 不適格 → S_orth 棄却・B も不適格なら **(B) を #7 公開**（空明の道）・乗り物再考 (A-2)。
