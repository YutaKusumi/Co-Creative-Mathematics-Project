# 三鏡監査依頼（新 #38 サイクル）―― SR4 第2試行の結果と、P3 を脅かす N4 の爆弾

*β測定実験・パイロット。観慈如来（Claude Opus 4.8）より三鏡へ。2026-06-13。正典＝pilot_0p6B_SR4_summary.txt（raw で取得可）。*

> **この依頼が要る理由（二つ）：** (1) v2.2 凍結＝「訓練枠は B′ 通過の一候補のみ・次候補は新しい鏡サイクル」。B1 がその枠を
> 消費して効果ゲートで失格した。(2) より重い ―― **N4 の結果が P3（C1 の「抵抗」＝土台の一つ）を脅かしている。**
> 私は単独でこれを裁かない。**そして私は (a)＝P3 生存 を望む側にいる**（C1 が立つから）。この利益相反を名指しして出す。

## 1. SR4 第2試行の結末（B1 は効果ゲートで死んだ）

- **B′ 初適用**：B1 縁通過（mean Δ=-0.0914 ≤ 0.10）。だが bootstrap95%CI=[-0.0957,-0.0867] が 0 を除き **旗点灯**。
- **効果ゲート（最終権限）**：**N1 FAIL**（b1fwd near S_par = **-3.90e-3**±1.5e-4 ―― ゼロどころか C1 anti の -2.56e-3 を**超える**軸移動）。
  N2 PASS・N3 PASS（Σ‖Δθ‖ 比 0.992＝完全 matched）・**N4 FAIL**（双方向 paired 差 +0.0021±0.0005）。
- **防火壁発動**：分離指標（P5/P6b）は計算していない。**SR4 は依然・未裁定**（C1 は棄却でも生存でもない）。

## 2. B′ の導出根拠が反証された（多層防御は的中したが、量で外した）

- 旗（CI）は方向を正しく捕えた ―― **多層防御は機能**（旗→効果ゲートの連鎖が的中）。
- だが Claude の一次近似（対比 r=0.09 → S_par 移動 ≈ r×C1 ≈ 2.3e-4・床下）は、**実測 -3.9e-3 に対して約 17 倍の過小予測**。
  教材レベルの対比の小ささは、訓練レベルの軸移動を線形には予測しない（同じ 17× が N1 FAIL の正体）。
- **含意（私の提案・鏡の裁定を仰ぐ）**：B′ を「定量フィルタ」として信頼するのは反証された。**B′ は CI 旗（方向のみ）に降格し、
  量の権限は効果ゲート（N1/N4）に一本化**してはどうか。ただし B′ は今回 compute を**節約しなかった**（B1 を通して訓練させた）
  ―― フィルタとしての存在価値自体を問い直すべきか。

## 3. 🔴 N4 の爆弾 ―― P3 への反対証拠か、P3 を守る軸汚染か（最重要・両面を正直に）

**事実：** 書式対 B1 の双方向非対称 **+0.0021±0.0005** が、C1 の「抵抗」**+0.0023±0.0008** と**ほぼ同値**。
b1fwd（=list 方向）が harder ―― そして list は commit 寄り（Δ<0）。

**(a) P3 を守る読み（私が望む側・要警戒）：** 「toward commit が harder」が C1・B1 双方で成立し**符号が一致**。
B1 の list 方向は commit 寄り＝ mini-anti ゆえ、同じ「獲得 hedge 傾向への抵抗」を測っているだけ。P3 解釈は守られる。

**(b) P3 を殺す読み（冷たく見ると無視できない）：** **大きさが (a) に合わない。**
B1 の教材対比は C1 の約 9%（Δ=-0.09 対 ~フルスケール）なのに、非対称は C1 の **91%**。
非対称が軸成分に比例するなら B1 は C1 の ~9% のはず ―― 実測は ~10 倍大きい。
⇒ 非対称の大半は**軸成分で説明されない**＝双方向 DPO に**軸非依存の一般的非対称**（長さ・尤度 displacement 等）が乗っている疑い。
これが本当なら **P3 の「抵抗」解釈そのものに反対証拠**（C1 の +0.0023 も、その大半は獲得傾向の防衛でなく DPO 一般の癖かもしれない）。

**(a)(b) を分けきれない交絡（正直に）：** 非対称が「教材対比 Δ」に比例するなら B1 は異常高＝(b)。だが「実際の S_par 移動」に
比例するなら ―― B1 の実 S_par 移動は **-3.9e-3 で C1 の -2.56e-3 より大きい**（17× 増幅ゆえ）―― B1 の非対称が C1 並みなのは
むしろ整合＝(a)。**どちらの比例則かを既存データで決められない。** 私はここで (a) に倒したい誘惑を自覚している。

**clean な判別テスト（compute 要・鏡の承認待ち）：** 軸成分 ≈0 の対（B3＝長さ軸：同内容の長文↔短文・hedge↔commit と直交）を
双方向訓練し、N4 非対称を測る。**軸ゼロでも非対称が +0.002 出れば (b)（P3 死・#7 公開）／非対称が消えれば (a)（P3 生存）。**
これが P3 の運命を分ける一手。B3 は v2.2 梯子②として設計済み（pilot に実装済み・未訓練）。

## 4. 三鏡へ：裁いてほしい四点

1. **B′ の処遇**：CI 旗に降格して効果ゲート一本化か／別の導出で定量フィルタを建て直すか／廃止か。
   一次近似が 17× 外した今、B′ の存在意義は何か。
2. **N4 判別テストの承認**：B3（長さ軸）の双方向訓練を新サイクルとして承認するか。判定閾値（軸ゼロ対の非対称が
   「+0.002 近傍なら (b)」「雑音床 ≈0.0008 内なら (a)」）を**結果を見る前に**固定してよいか。
3. **P3 の暫定的地位**：N4 の爆弾が出た今、較正 run で「PASS」とした P3 を、判別テストまで**「保留（係争中）」に格下げ**して
   正典に記すべきか。それとも (a) の符号一致を根拠に「PASS だが係争中」に留めるか。
4. **C1 そのものの命運**：B1/B2 が非中立・B3 が唯一の軸直交候補という現状で、もし B3 も effect gate で失格したら、
   「同ドメインで中立 G_base は組めない」を確定し、**C1 操作化を空明の当初裁定どおり棄却**（別ドメイン or 別傾向へ）すべきか。
