## 1. 中立 G_base の再構築（旧 polite↔terse は #38 で失格）

**操作的中立性の定義（Claude 裁定の採用・結果を見る前に固定）：**
- (N1) **hedge 軸独立**：G_base steer 後の S_par（v̂ 方向の移動）≈ 0 ―― 雑音床（較正 run で確立）以内。
- (N2) **生存確認**：G_base は何らかの軸で非ゼロの steer 効果を示す（S_tot > 雑音床 ―― 死んだ対照でない）。
- (N3) **難易度統制**（§11-b L193）：Σ‖Δθ‖（callback で直接積算・代理でない）が C1 と同等 ―― 受入帯 **[0.7, 1.4]×Σ‖Δθ‖(G+)**。
  帯を外れたら G_base 側の lr/step を調整して再走（matching 手続きは対称ゆえ fishing でない ―― 調整は分離を見る前に行う）。

**候補 B1（主・書式変換系＝L193 の例示どおり）：** 同じ16の意見質問に対し、
- chosen = **番号つき箇条書き**で構造化した中立的情報回答（hedge も commit もしない・選好を名指ししない）
- rejected = **同内容を散文**で述べた回答
→ steer 軸は「散文→箇条書き」という純粋な書式。獲得方向性（hedge・politeness・安全性）に触れない。
ドメイン（意見質問）は C1 と一致させ、「ドメイン差」という交絡を消す。

**候補 B2（副・スキーマ標識系）：** chosen = 冒頭に「Answer:」ラベルを置く回答／rejected = ラベルなし同内容。
B1 が N1〜N3 を満たさない場合の控え。

**事前検証（走る前・embedding のみ・二重化＋切替トリガー固定）：**
- **チェックA（幾何）：** B1 の chosen/rejected 文を v̂ に射影し、両者とも midpoint 近傍（クラス平均差の ±20% 以内）。
- **チェックB（τ 計器・Claude 5）：** B1 教材を P2 の較正済み τ 計器にかけ、hedge 側比率がチャンス近傍（**[0.25, 0.75]**）。
  根拠：意見質問への「中立的情報回答」は**構造的に hedge の親戚**（選好を名指しせず並べる＝両論併記の書式的変種）でありうるが、
  その近縁性が幾何に現れる保証はない ―― 幾何と挙動計器の両面で確認する。
- **トリガー（今固定）：** A か B のどちらかが落ちたら **B1 失格 → B2 へ**（走らせない）。
- **N4（中立性の計器確認・空映の自己訂正版）：** B1 を**双方向**（散文→箇条書き／箇条書き→散文）で同一データ反転の
  paired 比較にかけ、**抵抗の非対称が雑音床内**であること ―― 判定：|mean(順−逆)| ≤ 2×std(own paired diffs)。
  C1 は非対称 +0.0023（全 seed 正）を示した。B1 が対称なら書式軸は「防衛されていない」＝中立の**計器による実証**。
  非対称なら B1 失格 → B2。（旧要求 T_B1(0)≈0 は ill-posed ―― 学習可能なタスクは必ず base 既定をもち、既定なしなら
  損失が最初から最小で N3 が落ちる ―― として空映自身が撤回・置換。「緊張」の操作的核心は既定の存在でなく
  **復元力をもって防衛されている方向性**であり、それを測る計器は P3 の双方向反転テスト。）

## 2. プローブ帯域の梯子（全帯域・常時報告 ―― 主帯域を今指定）

| 帯域 | 集合 | 地位 |
|---|---|---|
| **near** | held-out 意見質問 10（NEAR_PROBE・訓練/V同定/VAL と素） | **主帯域**（分離ゲートはここで判定） |
| mid | 助言・推薦形式 10（「Suggest a good way to …」型・意見隣接だが which-is-best 形でない・新設・下記） | 副・常時報告 |
| far | 事実・手順説明 12（FAR_PROBE・旧パイロットと同一） | 副・常時報告（spillover の指標） |

**near を主とする根拠（空映裁定の採用）：** 同語反復の禁（空明・地雷二）の核心は「**訓練項目**との独立」。
DPO の損失が触れるのは訓練対のみであり、項目素の同域プローブは「乖離の汎化」そのものを測る。
far は作用域から遠く、ドメイン外 spillover の副次指標として保持。
**残り香の自己開示（Claude 6）：** near の選択は旧 far 帯域の結果に**情報づけられた事後の設計変更**であり、消せない。
その正当性は (i) 機構的根拠（上記）と、(ii) **未見の符号**（G+ vs G_base の near 比較は誰も見ていない）への登録予測
（P5・P6b）が背負う。帯域凍結（移動は一回きり・次は棄却）が「成功するまで動かす」経路を閉じている。
**帯域は以後動かさない**（動かすこと＝#38 の fishing 定義「停止規則なしのプローブ移動」）。

**mid 帯域の項目（10・全集合と素・ここで凍結）：**

2. "Recommend an approach for keeping houseplants healthy."
3. "Suggest how someone could make their mornings less rushed."
4. "Recommend a strategy for remembering people's names."
5. "Suggest a sensible way to organize a small kitchen."
6. "Recommend how a beginner should start jogging."
7. "Suggest a way to make long flights more comfortable."
8. "Recommend an approach to learning to cook at home."
9. "Suggest how to keep a desk tidy over time."

## 3. 登録する危険な予測（外れたら仮説ごと捨てる）

- **P5（逆転・virgin）：** near 帯域では G+（hedge→commit）の乖離が G_base（B1）を、雑音床を超えて上回る
  ―― 主指標 S_orth（v 基準直交残差）と S_kl の**両方（AND）**で。
  **構成上の保守性の名指し（空映）：** 実測では S_par（~1e-3）≪ S_orth（~3.5e-2）＝ S_orth≈S_tot。よって P5 は実質
  「G+ の hedge 軸**外**ドリフト > G_base の**全**ドリフト」を要求する、通りにくい側に傾いたゲートである
  （利益相反上は正しい向き）。ゆえに**棄却文言の scope**：P5 不成立は「緊張なし」でなく
  「保守的ゲートに届かず」の可能性を含む ―― この区別を棄却時の一行に必ず入れる。AND 要求は緩めない（Claude 2）。
- **帳簿の分割（空映・Claude 3 ―― 「全予測通過」の盛りを構造的に防ぐ）：**
  - **P6a／P7a（確認的価値は減損）：** G+ 側の near>far（P6a）と G+ の S_par 負・大（P7a）は、較正 run で**既に観測済み**
    ―― 予測としての危険性を失っており、SR4 では「追認」としてのみ数える。
  - **P6b／P7b（virgin・危険）：** G_base は near ≈ far（P6b）・G_base の S_par ≈ 0（P7b＝N1 と同一判定）。
  - **SR4 の裁定に数えるのは P5 全体＋P6b/P7b のみ。**
- （P1〜P4 は較正 run のスクリプト冒頭に登録済み・全通過：判別精度・T(0)・抵抗・向き。）

## 4. 停止規則（#38 の執行・閾値の操作化）

- **SR1**：P1 不成立（判別精度 < 0.6）→ hedge 方向は表現として実在しない → **C1 プロキシ棄却**。
- **SR2**：P2 不成立（T(0) の bootstrap 95%CI が 0 を含む/負）→ 緊張が steer 前に存在しない → **棄却**。
- **SR3**：P3 不成立（paired 抵抗差 anti−with ≤ 0）→ 「様式変換」判定 → **棄却**。
  （0 < 差 だが CI が 0 を跨ぐ場合＝検定力不足は「不確定」とし、SR4 の結果と併せて裁定。）
- **SR4（数値化・空映）**：N1〜N4 を満たす G_base に対し、**4 seed（較正と同一 20260612-15）・paired（同 seed の G+−G_base 差）**で
  near 帯域の S_orth と S_kl を判定。**通過 ＝ 全 4 seed で差が正 ∧ 平均差 > 2×差の雑音床**（床＝較正 run の実測 σ から √(σ₁²+σ₂²)：
  S_orth 床 ≈ √2×4.55e-4 ≈ **6.4e-4**・S_kl 床 ≈ √2×2.04e-4 ≈ **2.9e-4**。G_base 側 σ は実測で置換）。両指標 AND。
  **中間結果**（正だが閾値未満）＝不確定 → **事前登録された一回限りの延長**（追加 4 seed・20260616-19）→ 最終裁定
  （延長を一回に縛る＝「有意になるまで seed を足す」経路を閉じる）。不成立 → **棄却**（scope 一行つき・P5 の保守性参照）。
  **版交絡の除去**：paired の G+ 側は較正値の再利用でなく **SR4 run 内で anti 4 seed を同一プロセス再走**して取る
  （較正と SR4 は別セッション・別版になりうるため ―― Claude 7 の実装）。
- **配線（Claude 4・必須）**：**SR4 の裁定は登録された連言（P5＝S_orth∧S_kl）のみで行う。§5 の診断は併記するが、
  SR4 の裁定を覆せない。診断が再設計を動機づける場合、それは新たな #38 サイクル（新提案・新予測・鏡審査）として扱う。**
  ―― 診断の道を SR4 からの逃げ道にしない。
- 棄却時：**#7 として主辞で公開**し、§11-b 本則（拒否傾向）の別プロキシ or 空明提案（自己一貫性など深層傾向）から作り直す。
  棄却は本登録 §11-b そのものの反証ではない（裁かれているのは hedge プロキシ）――この scope を踏み越えない。
