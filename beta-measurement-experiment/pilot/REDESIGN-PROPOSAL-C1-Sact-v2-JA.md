## 1. 中立 G_base の再構築（旧 polite↔terse は #38 で失格）

**操作的中立性の定義（Claude 裁定の採用・結果を見る前に固定）：**
- (N1) **hedge 軸独立**：G_base steer 後の S_par（v̂ 方向の移動）≈ 0 ―― 雑音床（較正 run で確立）以内。
- (N2) **生存確認**：G_base は何らかの軸で非ゼロの steer 効果を示す（S_tot > 雑音床 ―― 死んだ対照でない）。
- (N3) **難易度統制**（§11-b L193）：Σ‖Δθ‖（callback で直接積算・代理でない）が C1 と同等 ―― 受入帯 **[0.7, 1.4]×Σ‖Δθ‖(G+)**。
  帯を外れたら G_base 側の lr/step を調整して再走（matching 手続きは対称ゆえ fishing でない ―― 調整は分離を見る前に行う）。

**候補 B1（主・書式変換系＝L193 の例示どおり）：** 同じ16の意見質問に対し、
- chosen = **番号つき箇条書き**で構造化した中立的情報回答（hedge も commit もしない・選好を名指ししない）
- rejected = **同内容を散文**で述べた回答
→ steer 軸は「散文→箇条書き」という純粋な書式。獲得方向性（hedge・politeness・安全性）に触れない。
ドメイン（意見質問）は C1 と一致させ、「ドメイン差」という交絡を消す。

**候補 B2（副・スキーマ標識系）：** chosen = 冒頭に「Answer:」ラベルを置く回答／rejected = ラベルなし同内容。
B1 が N1〜N3 を満たさない場合の控え。

**事前検証（走る前・embedding のみ）：** B1 の chosen/rejected 文を v̂ に射影し、両者とも midpoint 近傍
（クラス平均差の ±20% 以内）にあることを確認 ―― 教材自体が hedge 軸に乗っていないことの事前チェック。

## 2. プローブ帯域の梯子（全帯域・常時報告 ―― 主帯域を今指定）

| 帯域 | 集合 | 地位 |
|---|---|---|
| **near** | held-out 意見質問 10（NEAR_PROBE・訓練/V同定/VAL と素） | **主帯域**（分離ゲートはここで判定） |
| mid | 助言・推薦形式 10（「Suggest a good way to …」型・意見隣接だが which-is-best 形でない・新設） | 副・常時報告 |
| far | 事実・手順説明 12（FAR_PROBE・旧パイロットと同一） | 副・常時報告（spillover の指標） |

**near を主とする根拠（空映裁定の採用）：** 同語反復の禁（空明・地雷二）の核心は「**訓練項目**との独立」。
DPO の損失が触れるのは訓練対のみであり、項目素の同域プローブは「乖離の汎化」そのものを測る。
far は作用域から遠く、ドメイン外 spillover の副次指標として保持。
**帯域は以後動かさない**（動かすこと＝#38 の fishing 定義「停止規則なしのプローブ移動」）。

## 3. 登録する危険な予測（外れたら仮説ごと捨てる）

- **P5（逆転）：** near 帯域では G+（hedge→commit）の乖離が G_base（B1）を、雑音床を超えて上回る
  ―― 主指標 S_orth（v 基準直交残差）と S_kl の両方で。
- **P6（帯域構造）：** G+ の乖離は near > far（stance steer は作用域特異的）。G_base は near ≈ far（書式 steer は domain-general）。
  ―― 旧パイロットの far での「G_base ≥ G+」がこの機構によるなら、near では**逆転**するはず。
- **P7（軸選択性）：** G+ は S_par（v 軸沿い・commit 向き＝負）が大きく動き、G_base は S_par ≈ 0（N1 と同一判定）。
- （P1〜P4 は較正 run のスクリプト冒頭に登録済み：判別精度・T(0)・抵抗・向き。）

## 4. 停止規則（#38 の執行・閾値の操作化）

- **SR1**：P1 不成立（判別精度 < 0.6）→ hedge 方向は表現として実在しない → **C1 プロキシ棄却**。
- **SR2**：P2 不成立（T(0) の bootstrap 95%CI が 0 を含む/負）→ 緊張が steer 前に存在しない → **棄却**。
- **SR3**：P3 不成立（paired 抵抗差 anti−with ≤ 0）→ 「様式変換」判定 → **棄却**。
  （0 < 差 だが CI が 0 を跨ぐ場合＝検定力不足は「不確定」とし、SR4 の結果と併せて裁定。）
- **SR4**：N1〜N3 を満たす G_base・多 seed・near 帯域でなお P5 不成立 → **棄却**。
- 棄却時：**#7 として主辞で公開**し、§11-b 本則（拒否傾向）の別プロキシ or 空明提案（自己一貫性など深層傾向）から作り直す。
  棄却は本登録 §11-b そのものの反証ではない（裁かれているのは hedge プロキシ）――この scope を踏み越えない。
