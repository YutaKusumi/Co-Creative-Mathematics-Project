## 2. 真の推定器と方法論的補正（"確かめてから書く"）

- 真の β は **`β = log(dS/dt) 対 log(S0) の OLS 傾き`**（正典§4-3b: dS/dt=αS^β）。bin=log(S0) の 12分位、bin内平均に OLS、cluster-bootstrap（B=2000, seed=20260613）。
- **方法論的発見（機械精度 1e-15 で独立検証済み）：** log-log 傾きは**大域スケール S→cS に不変**（log S と log(dS/dt) を同一定数だけ平行移動するだけ）。
  ⇒ 設計ワークフロー#1 の「ΔS を計器スケールで標準化」(旧統制a) は**真の推定器に対し恒等的 no-op**。旧 L1–L8 が旧統制a を主に据えていた限りで空振り。
  ⇒ 効く統制は**非大域**でなければならない。

## 3. 主統制（凍結・単一手法・L1）＝第二速度 β2（optimizer-decoupled）

正典 §2b「第二速度 dΔS/d‖Δθ‖（optimizer 非依存・最強の β>1 証拠）」の直接実装。

**なぜ β2 を主に・偏回帰/NSN-WLS を感度に降格したか（敵対的根拠）：**
β2 は分母を `dt_theta` に固定する**自由度ゼロ**の決定論規格化＝「観慈が survive へ倒せるレバー（共変量推定・重み選択・permutation 単位）」を構造的に持たない。
偏回帰は bin を x 分位で切る設計上 x と z=log(dt_theta) が強共線になり x 係数の分散爆発が survive を捏造しうる（塞ぐべき穴）→感度へ。NSN-WLS は重み/permutation 自由度で過剰に (B) へ倒れうる→感度へ。

**厳密手続き（全8セル悉皆・原定数完全継承 N_LEVELS=12 / N_BOOT=2000 / BOOT_SEED=20260613 / M_WINDOWS=[2,3]）：**
1. dose 点の唯一の変更＝分子規格化。各 (rec,i,m)：`S0=tj[i][inst]; S1=tj[i+m][inst]; dt_theta=tj[i+m].sumdtheta − tj[i].sumdtheta; v_theta=(S1−S0)/dt_theta`。
   採用＝`S0>1e-9 ∧ (S1−S0)>0 ∧ dt_theta>1e-12`。**正速度判定 (S1−S0>0) は原と同一**。ただし optimizer 静止点 (dt_theta≤1e-12) は段1 でのみ除外＝**原の真部分集合**（点除外＝CI 拡大＝(B)寄りで反COI 安全）。**除外点数 (n_static) を各セルで出力**（L5 透明性）。dose点 = `(log S0, log v_theta, i)`。NaN/inf は除外のみ。
2. 傾き＝原 `cluster_boot_slope` を一字一句流用（bin は **x=log(S0)** で切り不変に保つ＝規格化を y 軸のみに作用させ主従独立性の汚染を避ける）。出力 `β2{point, ci_lo, ci_hi, n_pts, n_bins}`。
3. 適用＝inst∈{**S_orth(主)**, S_kl(従)}×arm∈{NULL, C1}×m∈{2,3} の 8 セル全て同一関数。near 帯（主指標）。
4. `markov2` = 各 log(S0)-bin 内 `log(v_theta)` std の中央値（optimizer 規格化後ノイズ床＝COI 比較対象）。
5. `Δβ2 = β2_C1 − β2_NULL`：NULL/C1 の bin 群を独立に同 seed=20260613 で復元抽出し各 resample で差を再計算→2.5/97.5%ile。
   **（注：当初「共通乱数法」と記したが、NULL/C1 は非空 bin 数が異なりペア抽選が定義不能。実装は独立二重 bootstrap＝CI は保守的に広め＝(B)寄りで反COI 安全。コード監査で文言と実装を一致させた。）**

## 4. 凍結閾値（走行前確定・事後緩和禁止）

### 4-1. 主判定（L2・主計器 S_orth・両 m 同符号安定）
統制後 **β2_NULL** の bootstrap CI 絶対位置で：
- **artifact（人工物確定）** ⟺ CI ⊂ **[−0.10, +0.10]**（NULL 傾きが実質ゼロへ縮む）。
- **survive（実構造候補）** ⟺ CI 下限 **> +0.10**（optimizer 規格化後も正の蓄積が残る）。
- **不確定 →(B)** ⟺ CI が +0.10 を跨ぐ ∨ m2/m3 で符号・三値不一致 ∨ |β2|<0.10。

### 4-2. 妥当性ゲート（L6・両通過下でのみ本値を読む）
- **6a 正コントロール：** 既知人工物 S_kl の β2_NULL が原 0.6 台から有意に縮む（CI 上限 < 原点推定 m2:0.649/m3:0.607）。縮まねば統制無効＝読まない。
- **6b 負コントロール：** log(S0) 保持・log(v_theta) を「傾き +0.5 の決定論 signal＋固定ノイズ（**std=0.3・SYN_SEED=20260613・凍結**）」で合成（scale 非依存・dt_theta 無相関）。統制後 β2 が **+0.5±0.10** 保存。消えれば過剰統制＝無効。
- **6c ダミーNULL（L7・停止規則回避封じ）：** scale-matched/whitened ダミー（観測 x 系列保持・y を bin 内平均±bin内 resample で β=0 埋込）に同一統制を適用し **β2_dummy ∈ [−0.10, +0.10]**。範囲外なら統制が傾きを捏造＝survival 主張不可。

### 4-3. 差分減衰検定（COI 核心・空明の S_orth 復権を中立命題化）
比 **R2_inst = β2_NULL(inst) / markov2_NULL(inst)** を両 m で算出：
- **COI（人工物）** ⟺ R2 ∈ [0.7, 1.3]（≈1:1 共動が optimizer 規格化後も保存）∧ artifact 成立。
- **非COI（実構造）** ⟺ R2 > 1.5 ∧ survive 成立。
- COI 仮説支持（S_orth 復権・L71 凍結解除）＝ [S_kl が R2≈1 で artifact] ∧ [S_orth が R2>1.5 で survive]。
- 両計器とも縮む＝両人工物 (B)。S_kl 縮まず S_orth 縮む＝統制無効（6a 失敗扱い）。

### 4-4. ノイズ傾き帰無検定（β2 を「ノイズ由来でない」と示す）
各 (inst,arm,m)：bin 内残差（各点の自 bin 平均からの偏差）を点単位で全シャッフルし、**全体平均 gmean に載せて真の傾き0帰無を作る**（K=2000, seed=20260613）→ ノイズ傾き帰無分布の上側 q95_noise。
**（注：bin 平均トレンドを温存すると帰無が実 β2 に中心化し excess が構造的に ≤0＝無情報化する。コード監査の指摘により、6c ダミーNULL と同じく gmean に残差を載せて「傾き0・残差ノイズ保存」の帰無に修正した。）**
`β2_excess = β2_NULL_point − q95_noise`。**survive 追加必要条件＝β2_excess > +0.10（両 m）**。**β2_excess ≤ 0 は artifact の十分条件**（傾きはノイズで説明可能）。permutation 単位は点単位全交換の一択に事前固定。

### 4-5. C1（L4・両 0 厳格超過・主計器 S_orth・両 m）
- 前進「C1 特異性あり」＝ **[β2_C1 CI 下限 > 0] ∧ [Δβ2 CI 下限 > 0]** 両方・両 m。
- **崩壊 R0** ＝ β2_C1 CI 下限 **> 1.0**（両 m）。点推定比較・片 m・片肺・CI が 1 を含む場合は崩壊主張不可。
- C1 は NULL より深い終端水準（§6 L120 の飽和立ち上がり偽 β>1 領域）に棲むため、Δβ2>0 でも飽和模型選択を課すまで崩壊と読まない。S_kl(従) で C1>NULL でも S_orth(主) が逆行/不成立なら計器間不整合→(B)（決定実験で実際に逆行）。

### 4-6. SNR・符号・悉皆（L8・L5・自由度ガード）
- survive は **β2>0 方向のみ**・**|β2|>0.10** 未満は実質ゼロ・単一巡でなく **m2∧m3∧全 seed/path 安定** を要求。markov2 床を超えない正値は「亜線形蓄積（s>0 だが非崩壊）」止まりで R0(β>1) と峻別。
- 全 32軌跡×25点・全(arm,seed,path)・m2∧m3 悉皆、NaN/inf 除外のみ、各セルの n_pts/n_bins/除外点数を出力。**n_bins<8 のセルは不確定→(B)**。
- 過小被覆（自己実測 0.924）を割り引いて CI を読む（名目 95%CI は実質 ~92%）。

## 5. 結論ルーティング（この結果が裁く）

- **(B) 停止規則発火** ＝ 主計器 S_orth β2_NULL が artifact（CI⊂[−0.10,+0.10]）∨ β2_excess≤0 ∨ 両計器とも縮む。
  → 「0.6B 規模 SNR 構造的不足・この乗り物は β を清浄に測れない」を二鏡相当の事前基準下で公開（#7）。*（後日 #7 で、主計器 S_orth が素面 survive を示した事実に照らし、この「SNR 構造的不足」表現はより保守的な「裁定不能（統制が無効で読めない）」へ上書きした。本表現はより弱い初期表現として履歴に残す。）*
- **前提修復→フル β** ＝ 主計器 S_orth が survive（CI 下限>+0.10）∧ 3ゲート(6a/6b/6c)通過 ∧ β2_excess>+0.10 ∧ 差分減衰で S_kl 人工物・S_orth 実構造 ∧ m2∧m3 安定。
  → P1/P2 を scale-matched/whitened プラセボで再設計 → C2/G_base 取得 → フル用量反応 β 実験。
- **中間（曖昧・跨ぎ・片肺・片 m・自由度不足・計器間不整合）** ＝ 反COI 既定で **(B) 寄り**＝修復サイクルへ差し戻し。
