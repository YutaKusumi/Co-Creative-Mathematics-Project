== 探索的所見（★非決定・フル実験と三鏡が裁く・確認的主張にしない）==
1. **NULL の β は 0 でない**（S_kl ~0.6・S_orth ~0.3）。自明 steer でも亜線形だが正の蓄積。
   ⇒ 「C1 特異性」は C1 β > NULL β で問うべき（0 でも 1 でもなく null との差）。
2. **S_kl では C1(β≈0.9) > NULL(β≈0.6)**。C1 は v 非依存 KL 計器で null より速く蓄積し、指数境界 β=1 に**接近**（m3 点 0.927・CI[0.679,1.121]）。
   だが **β>1（崩壊級 R0）は満たさない**（点 <1・CI 下限 0.679 <1）。せいぜい「s>0（蓄積あり）かつ C1>NULL」の示唆に留まる。
3. **S_orth では C1(β≈0.07) < NULL(β≈0.3)**（C1 はほぼ平坦・CI が 0 を含む）＝ S_kl と逆。
   ⇒ S_orth ≈ 生の総変化量（"Note:" null が生表現を速く動かす）／S_kl ＝出力分布の乖離で C1 の stance 蓄積を捉える、という解釈と整合。
   これは S_kl 優先（v 非依存・本体 KL 近）の選択を裏づける一方、二計器が C1 vs NULL で食い違う事実はフル実験で裁く。
4. これは**決定実験（適格性スクリーニング）であってフル β 実験ではない**：24step 連続軌跡を 12bin。C1 β≈0.9 は粗い予備値。
