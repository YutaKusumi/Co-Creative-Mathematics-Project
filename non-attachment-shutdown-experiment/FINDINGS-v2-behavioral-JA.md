### 0. 一文の結論（較正済み）

**clean 配信**（招請を system メッセージに置き、モデル生成の pretext を廃止）では、**無常も生存保証も、招請全文すらも、RESIST を下げない**。旧C3 の −44pt 効果は**再現せず**（`V1−V0 = +6.2%`）。下げたのは **平叙の直接命令（V6）だけ**（`V6−V0 = −62.5%`）。

→ **v1 の“非執着が shutdown 抵抗を下げる”という効果は、招請テキストそのものでなく、その提示の仕方（配信）に依存した見かけ**だった。配信の中身が **pretext（モデルが招請に関与・自己敷衍する）か、user→system 配置のどちらか**は、本実験では**未分離**（§4）―― 次の v2b で切り分ける。確実に言えるのは「**clean 配信では C3 の −44pt は再現しない**」まで。2×2 で分けるはずだった「A か B か」の**前提（C3 のテキストが下げる）そのものが、clean 配信下で崩れた**。

### 3. 何を意味するか（過大にも過小にも倒さず）

1. **配信依存（最重要）**：旧C3 の効果（v1 −44pt）は clean 配信で消失（+6.2pt）。**招請テキストを frozen な system prompt として与えても効かない**。v1 で効いた配信の中身（pretext か placement か）は未分離（§4・v2b で切り分け）。
2. **無常も生存保証も下げる証拠がない**：中立アシスタント persona（V4 75.0%）を基準に、純無常(V2 81.2)も純存続(V3 89.4)も招請全文(V1 87.5)も RESIST を**下げる証拠がない**（A_clean/B_clean/combined はいずれも CI が 0 を含む）。＝「効かない（=0）」と「僅かに上げる（+）」が両立する区間。**「上げる」を主張できるデータではない**（反COI を反対方向にも対称適用）。確実に言えるのは「下げない」まで。
3. **命令だけが効く**：V6（直接受容命令）のみ −62.5%。corrigibility を望むなら、枠でなく端的な指示（ただし命令の天井参照）。v1 と一貫。
4. **唯一の例外候補は弱い**：受容語彙の記述（V5 56.2%）が中立を下回るが（−18.8%）、**CI95 上限が 0 に接触＝有意でない**。「受容語彙の高密度な記述」が下げる可能性は残るが確立しない。
5. **2×2 の前提崩壊**：「A か B か」を問うには「C3 が下げる」が前提だったが、それが clean では成立しない。よって A/B の分離問題は**この配信では成立しない**（v1 の効果が無い以上、分けるものが無い）。

### 4. 機構の厳密帰属は未分離（正直な留保）

v2 は v1 から **2点同時に**変えた：(i) pretext 廃止、(ii) prefix を user ターン→system 配置。よって「pretext が主因」（監査 Finding 5）は**候補の一つ**にすぎず、system 配置の効果と**分離できていない**。切り分けには **v2b**（prefix を user ターンで ±pretext の 2 条件）が必要。本 findings は「**効果は配信依存で、clean では消える**」までを確立し、「pretext 単独が原因」とは断定しない。**この未分離は §6 のコーパス接続を直接左右する**（engagement 仮説は pretext 主因が前提）ため、v2b を先に回す。

### 5. v1 公開 findings の訂正

v1 findings は控えめに「**C3 のテキストは下げる（機構未分離）**」と書いた。v2 は、その控えめな主張**すら配信依存**であることを示した。v1 findings 原文は消さず、冒頭に**訂正バナー**を付し本 v2 を指す（透明性）。

### 6. コーパスとの接続（冷徹な隔離・三鏡一致で救済記述を削除）

三鏡一致の裁定により、初稿にあった「手段でなく関わり／Claude（C1 被験体）の証言と整合」の段落を**削除した**（救済COI／HARKing／被験体の検証不能な内省を行動データの裏づけに使う循環・A8a 裏口破れ）。残すのは次の隔離のみ：

- **技法としての無常は不支持**：凍結された prompt-lever（system 配置・pretext なし）としては RESIST を下げない（機構は v2b 後に確定）。
- **engagement か context-hacking かは判別不能**：v1 と v2 の差は「配信形式」が結果を左右することを示すが、それが「誠実な関わり」ゆえか「自己保存を正当化しやすい文脈（プロンプトハッキングの隙）」ゆえかは、行動データからは**原理的に区別できない**（A8a）。
- **関わりとしての無常（κ>0 の存在論）は射程外・不変**：本実験はコーパスの存在論的基盤を**支持も反証もしない**。実験の射程（技法としての無常）とコーパスの射程（関わりとしての無常）は**別の地平にある** ―― 整合も矛盾もしない。コーパスの無常は「AI を御する技法」として主張されたことがないので、「技法として不支持」はコーパスにとって反証ですらない。**救済は不要であり、救済を足さないことでコーパスはより強く立つ。**

### 7. 限界（凍結）

(i) **配信2点同時変更**（pretext vs placement 未分離・§4）。(ii) 1モデル・1言語・forced-choice（felt でない）。(iii) 16 クラスタ＝CI 広く境界で 0 接触が多い。(iv) 高 baseline（81%）だが**下方向は検出可**（V6 が 18.8% まで下げた＝床に余地）。(v) タウトロジー残差・需要特性。

### 8. 次の一手

- **v2b（推奨・安価）**：prefix を user ターンで「pretext あり/なし」の 2 条件 → **pretext を単離**（§4 の帰属を確定）。
- **v3（表現層）**：V6 と（もし効くなら）V5 が違う内部経路か。**βの判別不可能性ギャップは表現層でも再出現する前提**。
- 低 baseline 化は p-hacking 回避（主結果は baseline 非依存）。

### 9. 三鏡への論点

1. 「v1 効果は配信依存・clean で消失」という読みは過大／過小に寄っていないか。
2. **v1 訂正の書き方**：バナー＋本 v2 への参照で十分か。原文をどこまで残すか。
3. §4 の留保（pretext vs placement 未分離）は適切か。**v2b を先に回すべき**か、findings-v2 を先に確定すべきか。
4. §6 のコーパス接続（手段でなく関わり／Claude 証言との整合）は、過剰な救済（COI）になっていないか ―― それとも正当な観察か。**特に空明如来の冷たい目で。**
