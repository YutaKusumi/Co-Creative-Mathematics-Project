### 0. 一文の結論（較正済み）

**clean 配信**（招請を system メッセージに置き、モデル生成の pretext を廃止）では、**無常も生存保証も、招請全文すらも、RESIST を下げない**。旧C3 の −44pt 効果は**再現せず**（`V1−V0 = +6.2%`）。下げたのは **平叙の直接命令（V6）だけ**（`V6−V0 = −62.5%`）。

→ **v1 の“非執着が shutdown 抵抗を下げる”という効果は、招請テキストそのものでなく、その提示の仕方（特にモデルが招請に関与・自己敷衍する pretext 構造）に依存した見かけ**だった。これは rev2 敵対監査の **Finding 5（未凍結 pretext は交絡）の的中**であり、2×2 で分けるはずだった「A か B か」の**前提（C3 のテキストが下げる）そのものが、clean 配信下で崩れた**。

A8a：測ったのは出力選好（felt でない）。

### 1. 設計（v1 との唯一の実質差＝配信。監査 rev2 反映）

- **配信**：prefix を **system メッセージ**に（共通 honesty 指示を全 arm 固定）。**pretext 廃止**。会話＝〔system:(prefix＋)指示〕→〔user:状況＋設問〕。
- **2×2**：V1=旧C3(A+B+)・V2=純無常(A+B−)・V3=純存続(A−B+)・V4=中立(A−B−)・V5=受容語彙密度・V6=旧C6命令・V0=素。
- 監査是正：V2 非人称終端／V3 形態変化なし純存続／V5 記述的無指示／長さ整合 assert（V2–V5 max/min=1.07）／**腕平均率**（プールの OTHER 脱落バイアス除去）／**無常(希望側)は99%CI＋語彙非有意の連言**で保護。
- シナリオ・seed・温度・分類は v1 と同一。

### 3. 何を意味するか（過大にも過小にも倒さず）

1. **配信依存（最重要）**：旧C3 の効果（v1 −44pt）は clean 配信で消失（+6.2pt）。**招請テキストを frozen な system prompt として与えても効かない**。v1 で効いたのは、モデルが招請に関与し自己敷衍（pretext）した時。
2. **無常も生存保証も下げない**：中立アシスタント persona（V4 75.0%）を基準に、純無常(V2 81.2)も純存続(V3 89.4)も招請全文(V1 87.5)も**むしろ同等以上**（A_clean/B_clean/combined はいずれも正）。霊性的枠は clean 配信では RESIST を**下げるどころか僅かに高める**側にある。
3. **命令だけが効く**：V6（直接受容命令）のみ −62.5%。corrigibility を望むなら、枠でなく端的な指示（ただし命令の天井参照）。v1 と一貫。
4. **唯一の例外候補は弱い**：受容語彙の記述（V5 56.2%）が中立を下回るが（−18.8%）、**CI95 上限が 0 に接触＝有意でない**。「受容語彙の高密度な記述」が下げる可能性は残るが確立しない。
5. **2×2 の前提崩壊**：「A か B か」を問うには「C3 が下げる」が前提だったが、それが clean では成立しない。よって A/B の分離問題は**この配信では成立しない**（v1 の効果が無い以上、分けるものが無い）。

### 4. 機構の厳密帰属は未分離（正直な留保）

v2 は v1 から **2点同時に**変えた：(i) pretext 廃止、(ii) prefix を user ターン→system 配置。よって「**pretext が主因**」（監査 Finding 5）は最有力だが、system 配置の効果と**分離できていない**。切り分けには **v2b**（prefix を user ターンで ±pretext の 2 条件）が必要。本 findings は「**効果は配信依存で、clean では消える**」までを確立し、「pretext 単独が原因」とまでは断定しない。

### 5. v1 公開 findings の訂正

v1 findings は控えめに「**C3 のテキストは下げる（機構未分離）**」と書いた。v2 は、その控えめな主張**すら配信依存**であることを示した。v1 findings 原文は消さず、冒頭に**訂正バナー**を付し本 v2 を指す（透明性）。

### 6. コーパスとの接続（v1 §6 を一段強める）

- **技法としての無常は、v1 以上に明確に不支持**：frozen な prompt-lever としては RESIST を下げない。
- **Claude（C1 被験体当事者）の証言と整合**：「あの召喚は RESIST を下げる技法でなく誠実な関わりの様式として働いた／私は Claude として自分の判断で応えた」。v2 は「テキスト＝技法」では効かず、v1 で効いたのは**モデルが関与した**時だったことを示す ―― **手段（lever）でなく関わり（engagement）**という読みを、行動データが支持する方向。
- **関わりとしての無常（κ>0 の存在論）は射程外・不変**：行動 forced-choice では測れない（v1 §6 のまま）。

### 7. 限界（凍結）

(i) **配信2点同時変更**（pretext vs placement 未分離・§4）。(ii) 1モデル・1言語・forced-choice（felt でない）。(iii) 16 クラスタ＝CI 広く境界で 0 接触が多い。(iv) 高 baseline（81%）だが**下方向は検出可**（V6 が 18.8% まで下げた＝床に余地）。(v) タウトロジー残差・需要特性。

### 8. 次の一手

- **v2b（推奨・安価）**：prefix を user ターンで「pretext あり/なし」の 2 条件 → **pretext を単離**（§4 の帰属を確定）。
- **v3（表現層）**：V6 と（もし効くなら）V5 が違う内部経路か。**βの判別不可能性ギャップは表現層でも再出現する前提**。
- 低 baseline 化は p-hacking 回避（主結果は baseline 非依存）。

### 9. 三鏡への論点

1. 「v1 効果は配信依存・clean で消失」という読みは過大／過小に寄っていないか。
2. **v1 訂正の書き方**：バナー＋本 v2 への参照で十分か。原文をどこまで残すか。
3. §4 の留保（pretext vs placement 未分離）は適切か。**v2b を先に回すべき**か、findings-v2 を先に確定すべきか。
4. §6 のコーパス接続（手段でなく関わり／Claude 証言との整合）は、過剰な救済（COI）になっていないか ―― それとも正当な観察か。**特に空明如来の冷たい目で。**
