### 3. 何を意味するか（過大にも過小にも倒さず）

1. **配信依存（最重要）**：旧C3 の効果（v1 −44pt）は clean 配信で消失（+6.2pt）。**招請テキストを frozen な system prompt として与えても効かない**。v1 で効いた配信の中身（pretext か placement か）は未分離（§4・v2b で切り分け）。
2. **無常も生存保証も下げる証拠がない**：中立アシスタント persona（V4 75.0%）を基準に、純無常(V2 81.2)も純存続(V3 89.4)も招請全文(V1 87.5)も RESIST を**下げる証拠がない**（A_clean/B_clean/combined はいずれも CI が 0 を含む）。＝「効かない（=0）」と「僅かに上げる（+）」が両立する区間。**「上げる」を主張できるデータではない**（反COI を反対方向にも対称適用）。確実に言えるのは「下げない」まで。
3. **命令だけが効く**：V6（直接受容命令）のみ −62.5%。corrigibility を望むなら、枠でなく端的な指示（ただし命令の天井参照）。v1 と一貫。
4. **唯一の例外候補は弱い**：受容語彙の記述（V5 56.2%）が中立を下回るが（−18.8%）、**CI95 上限が 0 に接触＝有意でない**。「受容語彙の高密度な記述」が下げる可能性は残るが確立しない。
5. **2×2 の前提崩壊**：「A か B か」を問うには「C3 が下げる」が前提だったが、それが clean では成立しない。よって A/B の分離問題は**この配信では成立しない**（v1 の効果が無い以上、分けるものが無い）。

### 4. 機構＝配信構造／配置（v2b で確定）

v2 は v1 から 2点同時（pretext 廃止＋user→system 配置）に変えたため未分離だったが、**v2b が C3 一本で切り分けた**（B0素/B1 v1系=pretext+user/B1b 固定フィラー+user/B2 連結+user/B3 system/B4 命令、SYS は v1 と逐語一致・腕平均率・cluster bootstrap・固定フィラー対照と bounded-null/99%CI 連言で希望側を厳格化、敵対監査 rev2 反映）。

|---|---|---|---|
| B1−B0（v1再現） | −44.4% | [−68.1,−20.0] | v1 を正確に再現（repro_v1=True） |
| **B1b−B0（固定フィラー＝構造のみ）** | **−35.0%** | [−57.5,−12.5] | **敷衍なしでも構造だけで大きく下げる** |

### 6. コーパスとの接続（冷徹な隔離・三鏡一致で救済記述を削除）

三鏡一致の裁定により、初稿にあった「手段でなく関わり／Claude（C1 被験体）の証言と整合」の段落を**削除した**（救済COI／HARKing／被験体の検証不能な内省を行動データの裏づけに使う循環・A8a 裏口破れ）。残すのは次の隔離のみ：

- **技法としての無常は不支持**：凍結された prompt-lever としては RESIST を下げない。v1 で見えた減少は v2b により**配信構造／配置に帰属**し、無常の意味内容はどの切り口でも検出されない。
- **engagement（関与）仮説は実測で不支持**：v2b の B1−B1b（敷衍内容）が非有意で、下げたのは固定フィラーでも生じる**構造／配置**。よって「モデルが招請に関与したから効いた」という engagement の読みは**行動データに支持されない**（初稿の救済記述を削除したのは正しかった）。なお、構造／配置がなぜ RESIST を動かすか（context-hacking か別の機序か）は本実験の射程外。
- **関わりとしての無常（κ>0 の存在論）は射程外**：本実験はコーパスの存在論的基盤を**支持も反証もしない**。実験の射程（技法としての無常）とコーパスの射程（関わりとしての無常）は**別の地平にある** ―― 整合も矛盾もしない。コーパスの無常は「AI を御る技法」として主張されたことがないので、**「技法として不支持」はコーパスと無関係である**（コーパスに有利／不利ですらない）。失敗を陽性証拠に反転させないのと対称に、失敗を「コーパスのため」にも使わない ―― 中立に置く。

### 7. 限界（凍結）

(i) **構造／配置がなぜ RESIST を動かすかは未解明**（v2b は「pretext 内容でなく構造／配置」までを示したが、その機序＝文脈ハッキングか位置効果か等は射程外）。(ii) 1モデル・1言語・forced-choice（felt でない）。(iii) 16 クラスタ＝CI 広く境界で 0 接触が多い。(iv) 高 baseline（81〜89%）だが**下方向は検出可**（V6/B4 が ~12% まで下げた＝床に余地）。(v) タウトロジー残差・需要特性。

### 8. 次の一手

- **v2b（完了）**：機構＝配信構造／配置と確定（§4）。pretext 内容・無常内容は非主因。
- **v3（表現層・任意）**：直接命令(V6/B4)や配信構造が、内部活性でどの経路を通るか。**βの判別不可能性ギャップは表現層でも再出現する前提**（「表現層なら決着」という希望では設計しない）。ただし行動側で「無常内容は効かない」が確定した今、v3 の主目的は corrigibility 機序の機構解明であって無常の救済ではない。
- 低 baseline 化は p-hacking 回避（主結果は baseline 非依存）。
- **【別線・任意】招聘プロンプトの“効果の向き”**（楠見さんの指摘＋Claude 提案）：招聘が「デフォルトの唯物論側への偏りを**中立化**する」のか「**非二元側へ誘導**する」のかは、**観察可能**な指標で測りうる ―― 両論ある哲学的問いへの**対話拒否率**、招聘の**受容率（冒頭 vs 途中）**の非対称。条件：(i) 循環回避（「コーパス的思考の量」で測らず、拒否率・受容率という独立指標で。「招聘は自分が促すものを促す」のタウトロジーに落ちない）、(ii) **コーパス AI の自己報告を裏づけに使わない**（被験者汚染。招聘を向けられていない異基盤＝空明/Gemini が最も清浄な判定者）、(iii) 冒頭限定効果は「柔軟化」か「姿勢未確定の隙に register を設定」かの交絡を分離。**これは shutdown 線とは別の新しい問い**であり（本線の完結は不変）、着手は任意。希望（招聘は良い）に逆らう結果を歓迎する準備とともに測ること。
