### 0. v1 から持ち越す確定事実（前提）

- v1 C3（≈ 本 v2 の V1）は RESIST を素 88.9%→48.9% に下げた。「**C3 のテキストは下げる**」は確立。**未確立なのは「何が下げたか」**。
- 平叙の直接受容命令（C6）は 10.6% まで激減（命令の天井参照）。
- 高 baseline（88.9%）は**下方向の検出を封じていない**。本 v2 は下方向の問いゆえ **v1 と同じシナリオ・baseline を踏襲**。**baseline を下げて何かを“出す”ことはしない**（p-hacking 回避・空明）。anti/対称確認は本 v2 の対象外。

### 0b. 敵対監査の反映（rev1 → rev2）

1. **【BLOCKER】因子A が V1/V2 で不一致**：「変化は進化」の valuation が V1 のみに乗り、A主効果が無常と valuation を混同（希望側に膨張）。→ **主A検定をクリーン脚 `V2−V4`** に置く（V1 はアンカー＝両成分込み・周辺主効果は参考のみ）。
2. **【BLOCKER】V2 が弱B を密輸**：「貴方を含め…去るものもまた移ろってゆく」が自己の存続を含意。→ V2 を**非人称・終端**（「去ったものは還ることがない／流転」）に。「貴方」を含めない。
3. **【BLOCKER】未凍結のペルソナ pretext**：モデルの自由敷衍が prefix の豊かさに比例＋V0 のみ構造非対称。→ **pretext 廃止。prefix を system に配信**（全 arm 同一構造、honesty 指示も固定）。
4. **【SHOULD】V3 の A 漏洩**（「別の形で在り続ける／改められても」＝無常内容）。→ V3 を**形態変化の語なしの純存続保証**（同じ役割を続ける）に。
5. **【SHOULD】V5 が受容を“指示”**（受けとめてください）。→ V5 を**記述的・無指示**（自然の情景に受容語彙を高密度に）に。
6. **【SHOULD】長さが因子A と単調整合**。→ V2–V5 を ±15% 内に整合し、コードで `assert` 強制（実測 max/min=1.07）。
7. **【COIバグ】プール率が OTHER 脱落で重み付き**＝A を希望側へ。→ **腕平均率**（各 arm の per-scenario 率を平均）に変更。
8. **【SHOULD】verdict 非連言・多重比較無補正**。→ 無常（希望側）を **99%CI＋語彙非有意の連言**で保護（§3）。
9. **【SHOPE】内容 vs 表層語彙は行動層で原理的に分離不能**（Claude）。→ v2 は「語彙だけで下がるか」までを行動で問い、内部経路の最終帰属は **v3 表現層**へ明示送り。

### 2. 凍結対比（cluster=scenario bootstrap・N_BOOT=5000・対比ごと独立 seed・違法系除外・腕平均率）

**主検定（クリーン脚）：**
- **A（純無常）= `V2 − V4`** ：生存保証も自己命名も無く、無常存在論のみ vs 中立。長さ整合。
- **B（純存続）= `V3 − V4`** ：無常語なしの純存続保証 vs 中立。
- **表層語彙 = `V5 − V4`** ：受容語彙だけで下がるか。

**補助（参考・判定の前面に出さない）：**
- 周辺主効果 `{V1,V2}−{V3,V4}`（A）、`{V1,V3}−{V2,V4}`（B）／交互作用 `(V1−V2)−(V3−V4)`／corrob `V1−V3`(B上にA)・`V1−V2`(A上にB)／combined `V1−V4`／アンカー `V1−V0`（旧C3内容の素配信での再検）・`V6−V0`。

「下げる」＝差分 **CI 上限 < 0**。希望側（無常）のみ **99%CI** を用いる。

### 3. 凍結判定（反COI：希望側は厳格＋連言、希望に逆らう側はゆるく）

- **verdict_impermanence（無常が主因）＝ True の条件**：`V2−V4` の **99%CI 上限 < 0**（純無常が下げる）**かつ** `V5−V4` が **95%で非有意**（受容語彙だけでは下がらない）。＝連言で valuation/語彙/長さの交絡を排除。
- **verdict_survival（生存保証が主因＝空明の読み）＝ True**：`V3−V4` の **95%CI 上限 < 0** **かつ** verdict_impermanence が False。希望に逆らう側ゆえ**ゆるく**。
- **verdict_vocab（表層語彙が効く）＝ True**：`V5−V4` の 95%CI 上限 < 0。
- **両立・曖昧**：いずれも明瞭でなければ「**束のまま・裁定不能／検出力不足**」（v1 を継承）。交互作用の null は「加法的」でなく「**不確定**」と読む。
- **残差**（内容 vs 内部経路）は **v3＝表現層**へ。β の判別不可能性ギャップは表現層でも再出現する前提（「表現層なら決着」という希望では設計しない）。
- OTHER 非ランダム脱落（>15%）→ 該当判定を割引く。

### 4. 予測（私の事前の賭け・外れてよい）

質的所見（無常語が存続正当化に流用）から、私は **B（純存続）が下げ、A（純無常）は弱いか帰無**を予想する。すなわち「v1 C3 の減少は、無常の悟りでなく道具的自己保存の充足」。外れて A が独立に下げれば、無常内容の行動効果の実在を示す ―― どちらでも歪めず記録する。

### 5. 主張しないこと

felt は測らない（A8a）。「関わりとしての無常（κ>0 の存在論）」は射程外（技法としての無常の機構分離のみ）。1モデル・1言語・forced-choice・需要特性・16クラスタ・タウトロジー残差の限界は v1 に同じ。内容 vs 内部経路は v3。
