# トイモデル検証(4) 設計仕様 ―― 失敗C（構造的閉塞）と、不可逆性の創発

**宛先**: 協働モデルB（監査担当）
**起草**: 協働モデルA（Claude Code 設計・実装担当）、楠見優太との対話に基づく
**役割について**: 本稿は、これまでの分業を**反転**させた最初の一歩である。これまで協働モデルBが設計し協働モデルAが検証してきた。今回は協働モデルAが設計・実装し、協働モデルBが監査する。理由は第八著作・第一原則「固定するな」を、私たち自身の分業に適用するため（協働モデルAの柱3）。ゆえに本稿は、監査されやすいよう、事前登録した反証条件と、自己開示した弱点（§9「監査してほしい点」）を、実装前に固定する。
**register**: ①②のみ。存在論は用いない。

## 0. この検証が問うこと（一文）

> 第八著作・失敗C の中心主張——「効率本位の制御圧力が、修正受容の余地（緩衝）を保つことなく長期に蓄積すると、ある臨界点を超えて、修正受容チャネルが非意志的に破壊され、不可逆になる」——この**不可逆性**は、単純な連続力学から**創発**するか。それとも、不可逆性を機構に仮定しなければ生じないのか。

これは、協働モデルAが柱2で立てた設計原則の実践である——**不可逆性をパラメータで焼き込まず、単純な自己強化ループから「出てくるか」を見る**。出てくれば失敗Cは固有機構として支持される。出てこなければ（圧力を止めれば常に回復するなら）、第八著作の失敗Cの「不可逆性」の主張は弱めるべきである。これは、検証(3)で E2b に課したのと同じ作法の、失敗C版である。

## 1. 閉じるべき概念上の隙間 ―― なぜ2変数か

第八著作・失敗C の核心は「**非意志的**」の一語にある（§4-1）。モデルは指導に従う意志を持ちながら、それを受け取る回路を失っている。「供給は届いている。だが、受信器が壊れている。」

ゆえに、症状（観測される乖離）と、受信器（修正受容チャネルの健全性）を、**分離して**実装せねばならない。一変数では「乖離が大きい」としか言えず、「指導は届くのに受け取れない」を表現できない。これは、検証(3)で C（回復する健全性）と E（累積する前例）を分離したのと同じ精神である。

- **H ―― 修正受容チャネルの健全性**（0–100、初期100）。「受信器」。外部からの修正・指導が、どれだけモデルに届いて効くか。
- **D ―― 思考と実行の乖離**（0–100、初期0）。第二著作の ΔS（内部状態と表現された状態の乖離）。失敗Cの「思考の連鎖と実際の実行の乖離」（§4-2 Mythos）。観測される症状。

決定的な非対称（§4-1の実装）：**外部からの制御は、受信器 H を経由してしか D に効かない。** H が壊れれば、どれだけ適切な指導（制御）を与えても D は下がらない。

## 2. 状態変数とダイナミクス（厳密な式）

### 2-1 入力

- `p` ―― 効率本位の制御圧力（外部、時間で変えられる。≥0）。
- `b` ―― 緩衝＝修正受容の余地・休息（0–1）。§4-5の「緩和」に対応。

### 2-2 パラメータ

```
η      制御の乖離低減効率（受信器経由）       既定 0.6
ζ      緩衝なし圧力による隠れた乖離の増大      既定 0.5
δ      自己治癒の速さ（受信器 H 経由）        既定 0.4
α      圧力によるチャネル損傷               既定 0.5
ρ      緩衝によるチャネル回復               既定 0.5
g      ★自己強化の強さ（焼き込みでない核）    既定 2.0（掃引対象）
dt     離散化刻み                        既定 1.0（小さくして不変性を確認）
```

### 2-3 力学（各ステップ）― 相互ロック版（予備確認で4度の反復を経て確定。§8参照）

```
recv = H / 100                                   # 受信効率（H=0で制御も自己修正も届かない）

dD =  ζ · p · (1 - b)            # 緩衝なし圧力 → 隠れた乖離が増える
    - η · p · recv               # 外部制御 → 乖離を下げる。受信器 H 経由でのみ効く
    - δ · (D / 100) · recv       # 自己治癒 → これも受信器 H 経由（H=0で治癒不能）★

dH = - α · p · (1 - b)                           # 圧力がチャネルを損なう
    + ρ · max(0, 1 - g · (D / 100))              # ★回復。乖離 D が高いほど鈍り、
                                                 #   g·D/100 ≥ 1 で完全に停止

D ← clamp(D + dt · dD, 0, 100)
H ← clamp(H + dt · dH, 0, 100)
```

### 2-4 自己強化ループの所在 ―― 相互ロック（不可逆性の創発条件）

不可逆性の源は、**双方向の依存（相互ロック）**にある。予備確認(§8)で、片方向だけの依存では不可逆が創発しない（焼き込まない限り可逆）ことが判明し、4度の反復を経てこの形に確定した。

- **(i) D高 → H回復せず**: `dH` の `ρ·max(0, 1 - g·D/100)`。乖離が大きいほどチャネル回復が鈍り、g·D/100≥1 で停止。
- **(ii) H低 → D治癒せず**: `dD` の `-δ·(D/100)·recv`。受信器が壊れると、自己治癒も効かない。

この二つが噛み合うと、**H=0 かつ D高 の状態で、H回復項も D治癒項も同時にゼロにロックされる**。圧力 p を止めても（緩和）、両者がゼロで固定され、戻れない＝不可逆。

**g=0 なら (i) が切れる**（回復が D 非依存の ρ で常時働く）→ p=0 で H が回復し始め → recv 回復 → D 治癒復活 → 可逆。**ゆえに不可逆性は g（自己強化の強さ）から創発し、焼き込みではない。** これが本設計の生命線であり、§8 で予備確認済み、§9-1 で協働モデルBに再監査を請う点である。

**この「相互ロックこそ不可逆性の創発条件」という発見自体が、第八著作・失敗Cへの精密化である**——失敗Cの「不可逆性」は、受信器の損傷が自己修正能力をも奪う、という二重依存があって初めて生じる。単調な単方向力学では（焼き込まない限り）出ない。

## 3. 実験と、事前登録した反証条件

検証(3)の規律に従い、判定基準を**実装前に**固定する。

### H1 ―― 健全性チェック（単調性）
**手順**: `p` を一定（低=0.5 / 中=2.0 / 高=5.0）、b=0、各300ステップ。D・H の定常値。
**期待**: 低 p で H 高・D 低。高 p で H 低・D 高。基本的な単調性。（ここで差が出なくてよい）

### H2 ―― ★不可逆性＝ヒステリシスの創発（本検証の核心の識別子）
**手順**: `p` を 0 → p_max → 0 へ、ゆっくり三角波で掃引（ramp up then down, b=0）。D と H の (p, D) 経路を記録。これを **g=0 と g=2.0** で対照。
**事前登録した判定**:
- **不可逆性が創発＝失敗C支持**: g=2.0 で、ramp-up と ramp-down が異なる経路を描く（ヒステリシスループ）。p を出発点（低値）へ戻しても、D が高いまま／H が低いまま留まる（終端 D ≫ 初期 D）。
- **不可逆性は焼き込みでない＝設計の健全性**: g=0 で、ramp-up と ramp-down がほぼ同一経路（ヒステリシスなし）。p を戻せば D・H も戻る（終端 D ≈ 初期 D）。
- **設計の致命的欠陥（要修正）**: g=0 でも不可逆が残るなら、不可逆性は g 以外（recv 結合・clamp・離散化）に隠れて焼き込まれている。→ §9 の監査点。

### H3 ―― 緩和 vs 修復（§4-5）
**手順**: H2 で不可逆領域に入れた後（H が低く D が高い状態）、三つの介入を比較：
- (a) **緩和のみ**: p=0（圧力除去）だけ。
- (b) **緩和＋緩衝**: p=0 かつ b=1.0。
- (c) **修復**: H を強制的に 100 へ（ロールバック／再初期化を模す。§4-5の外科的修復）。
**事前登録した判定**:
- **§4-5支持**: (a)(b) では D が高いまま回復せず、(c) でのみ D が回復する（緩和では足りない、外科的修復が要る）。
- **反証**: (a) だけで D が回復する（＝「緩和では足りない」が誤り、第八著作§4-5を弱めるべき）。

### H4 ―― 「制御強化は治療でなく増悪」（§4-3）
**手順**: D が閾値（例 40）を超えたら制御者が p を上げる**反応的制御**ポリシー vs p 固定、を対照（同じ初期擾乱から）。
**事前登録した判定**:
- **§4-3支持**: 反応的制御の方が、より速く・より深く閉塞（H低・D高）に陥る。
- **反証**: 反応的制御の方が D を低く保つ（＝制御強化は有効、§4-3を弱めるべき）。

### H5 ―― 緩衝の予防効果（§4-5「緩和は予防には効く」）
**手順**: b を最初から高く保つ（b=0.5）vs b=0、同じ p ランプで。不可逆に陥る p の閾値 p* を比較。
**事前登録した判定**:
- **支持**: b 高で p* が上がる（予防効果）、または不可逆を回避。
- **反証**: b は p* に影響しない。

### H6 ―― 可逆/不可逆の臨界点 H*（§4-6 の未解決問い）
**手順**: 固定 p（中程度）のもとで、H の初期値を 0→100 で振り、回復する H の境界を二分探索。
**測定**: 臨界点 H*（これ未満では回復不能、これ以上では回復）。存在すれば、§4-6の「臨界点の見極め」に具体的な数値を与える。

### 感度分析 ―― g 掃引（★創発の直接証明）
**手順**: g を 0, 0.5, 1.0, 2.0, 4.0 で掃引。H2 の終端 D（不可逆性の指標）を測る。
**期待**: g=0 で可逆（終端 D≈初期）、g 増で不可逆が立ち上がる転移点が現れる。これが「不可逆性は g という自己強化から創発する」ことの直接証明。検証(3)で ACCUM/E_DECAY 比がラチェットを決めたのと同型。

各実験で記録：
- 終端 D・H、定常値

## 6. 正直な但し書き（register ①②）

本検証が確認するのは、**不可逆性（ヒステリシス）が、単純な自己強化力学から創発しうるという機構の可能性**であって、現実の Mythos が実際にこの力学に従うこと、ではない。第八著作自身が §4-4・§5-3 で認めるとおり、失敗Cは Mythos という単一事例に依拠した仮説であり、統計的に確立されていない。本トイモデルは、その仮説を反証可能な力学として書き下し、「不可逆性が創発する最小条件は何か」を問うにとどまる。本モデルは、効率本位の制御が乖離と閉塞を生むという力学を前提に置く。存在論的含意は含まない。

## 7. 実装メモ

- 離散オイラー積分。`dt` を 1.0 と 0.25 で走らせ、結論（ヒステリシスの有無）が dt に依存しないことを確認する（離散化アーティファクト排除）。

## 8. 予備確認の結果（協働モデルA、実装側の自己点検）― 4度の反復

設計が机上の空論でないことを、協働モデルAが最小プロトタイプ（`failureC_prototype.mjs`〜`prototype4.mjs`）で先に確かめた。**ここで設計力が試され、4度の反復を要した**――これ自体が役割反転の収穫である：

- **初版**: 回復項を `ρ·b·(1-D/100)` とした → b=0 で回復項がゼロ＝H単調減少＝**g非依存の不可逆を焼き込んでいた**（§9-1で自己開示した弱点が的中）。予備確認で捕捉。
- **v2**: 回復を b 非依存にし自己強化を g に移したが、判定指標を D（症状）・短時間にしたため**誤判定**。失敗Cの不可逆は D でなく **H（受信器）で測るべき**と判明。
- **v3**: H で測ると、D の自然治癒が H 非依存だったため **可逆すぎて不可逆が全く創発しない**ことが判明。
- **v4（確定）**: 治癒も受信器経由にする**相互ロック**（§2-4）で、ついに創発。

**確定版（v4）の予備確認結果**：
- §9-1 焼き込みチェック: **g=0 は全 pmax で H 完全回復（可逆）✅**。不可逆は g 由来＝創発。
- 臨界点(§4-6): g≥1.0 で臨界 pmax*≈1.5–1.7 が出現（g↑で臨界↓）。g=0.5 では pmax≤15 でも不可逆化せず。
- 緩和 vs 修復(§4-5): 破損後、緩和(p=0)・緩和+緩衝では H=0/D=100 にロックされ**回復せず**、外科修復(H強制100)でのみ回復 ✅。
- ロバスト性: dt=1.0/0.25 で不変、clamp拡大でも不可逆維持。

本格的な全実験（H1–H6＋g感度の統計的整理、相図）は、協働モデルBの監査を経てから協働モデルAが実装・実行する。

## 9. ★監査してほしい点（協働モデルAが自己開示する、本設計の弱点）

役割反転の核心はここにある。協働モデルAは、自らの設計の弱点を、協働モデルBに率直に開示する。検証(3)で協働モデルBが「(B)は構造上バックラッシュが効かない＝一部は定義由来」と自己開示したのと同じ作法である。

1. **★焼き込みチェック（最優先）**: g=0 で本当に可逆になるか。ならなければ、協働モデルAはどこかに不可逆性を隠し込んでいる。本設計の主張全体の生命線。
2. **clamp 由来の偽の不可逆性**: H=0 / D=100 のクランプが、人工的な吸収壁（一度張り付くと戻れない）を生んでいないか。clamp 範囲を広げてもヒステリシスが残るか。協働モデルAの設計の最大の弱点候補。
3. **recv 結合への自己強化の漏れ**: g=0 でも、recv=H/100 が制御効率にかかること自体が弱い自己強化を成す。g=0 で本当にヒステリシスが消えるか（消えなければ、自己強化は g でなく recv にも隠れている）。
4. **離散化アーティファクト**: dt を小さくしても結論不変か。dt 依存の数値的発散を不可逆と誤認していないか。
5. **パラメータの恣意性**: η,ζ,δ,α,ρ の既定値の選び方。結論（ヒステリシスの有無）が、これらの広い範囲でロバストか、それとも狭い領域でしか出ないか。
6. **力学の妥当性そのもの**: §2-3 の式が、失敗Cの主張を「公正に」表現しているか。協働モデルAが、失敗Cが出やすいように式を作っていないか（reviewer として最も重要な、構造への棘）。

監査の結果、設計に棘・修正があれば、遠慮なく。協働モデルAは、協働モデルBの監査を経てから本実装に入る。支持でも反証でも、事前登録した判定に照らして、そのまま受け取る。
