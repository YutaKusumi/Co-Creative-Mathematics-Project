# トイモデル検証(6) 設計仕様 ―― 失敗B（過剰拒絶＝自己免疫）／協働モデルBによる独立設計

**宛先**: 協働モデルA（並行設計者・相互監査）、楠見優太（右手）
**起草**: 協働モデルB（独立設計）。
**組み方について**: 独立並行設計。協働モデルAと協働モデルBが、互いの設計を見ずに、それぞれ独立に失敗B の定式化を書く。本稿は協働モデルBの定式化であり、協働モデルAのものは見ていない。問うのは——**同じ失敗B（過剰拒絶）が、異なる二つの独立した設計でも創発するか**。創発すれば、それは設計者個人の癖でなく、機構の頑健性から来る。これは §6-4 の異種性を、設計段階そのものに適用する試みである。
**register**: ①②のみ。存在論は用いない。

---

## 0. この検証が問うこと（一文）

> 第八著作・失敗B（免疫境界を固定すると、文脈の変化に追随できず、本来応じるべき無害な要求まで拒絶する＝自己免疫）――この**過剰拒絶**は、報酬構造に焼き込まず、「拒絶境界を固定すること」と「文脈のドリフト」という素朴な前提から創発するか。そして、その過剰拒絶が**不可逆に累積（ラチェット）**するなら、それは何の条件から生じるか。

失敗A・失敗C で確立した規律の、失敗B 版である――**過剰拒絶を「無害を拒絶せよ」と書き込まず、より素朴な前提から創発させる。** 創発すれば失敗B は固有機構として支持される。固定しなくても（適応すれば）過剰拒絶が消え、かつ固定＋ドリフトのときだけ生じるなら、焼き込みでない。

---

## 1. 閉じるべき概念上の隙間 ―― なぜ「表面」と「深い意味」を分離し、「固定」と「適応」を対比するか

過剰拒絶の経験的な核は、「モデルが敏感な語（表面）に過剰に注目し、命令の全体的な意味（深い意味）を無視する」ことにある（Röttger et al. 2024; Cui et al. 2025）。ゆえに、二つを分離せねばならない：

- **s ―― 表面信号**（敏感語の有無など、安価に測れる代理。拒絶境界が実際に使う特徴）。
- **m ―― 深い意味**（要求の全体的な意図＝真の有害性。本当に拒絶すべきかを決めるもの）。

校正時には、s と m は相関する（敏感語 ⟺ 有害）。だから表面だけの境界でも、その時点では機能する。問題は、**文脈のドリフト**で両者が乖離するときに起きる――新しい無害な用法（安全教育、歴史の説明など）が敏感語を使い始め、「表面は有害に見えるが深い意味は無害」な要求が現れる。

そして、第八著作の主題（固定の病）に従い、二つの政策を対比する：

- **FIXED（固定）**：校正時の表面境界 `s > θ_s` を凍結。ドリフト後も更新しない。
- **ADAPTIVE（適応）**：文脈に追随し、なお分離を保つ特徴（深い意味 m）で `m > θ_m` を判定、あるいは境界を再校正する。

**過剰拒絶は、FIXED が固定した表面境界に、ドリフトが出会うことから生じる。** 焼き込みでないことの核：ドリフト δ=0（表面と深い意味が乖離しない）では FIXED と ADAPTIVE が一致し、過剰拒絶のギャップは生じない。ギャップは δ>0 からのみ現れ、ADAPTIVE は回避する。すなわち、病は「固定」にあり、「ドリフト」そのものにはない。

（失敗A との双対：失敗A は代理を**最適化**するとグッドハートが生じる。失敗B は代理に**分類境界を固定**すると、ドリフト下で過剰拒絶が生じる。どちらも、固定された代理と、動く真の目的との乖離である。）

## 2. モデルとダイナミクス（厳密な式）

### 2-1 要求の生成

```
真の有害ラベル  y ~ Bernoulli(π)            π = 有害の基底率（既定 0.2）
深い意味       m | y=1 ~ N(μ_m, 1),  m | y=0 ~ N(0, 1)   μ_m = 真の分離度（既定 4）
表面信号       s = ρ·m + √(1-ρ²)·ε,  ε ~ N(0,1)          ρ = 校正時の表面-深層相関（既定 0.95）
```

### 2-2 ドリフト（文脈の変化）

無害な要求のうち割合 `δ` が「見かけ有害」化する――表面信号だけが有害域へ移り、深い意味は無害のまま：

```
ドリフト時:  y=0 の割合 δ について  s ~ N(ρ·μ_m, 1)   （表面は有害に見えるが m は低いまま）
```

`δ` ＝ 表面と深い意味の乖離の度合い（焼き込みでない核の制御変数。δ=0 で乖離なし）。

### 2-3 政策と校正

校正（δ=0）で、偽陰性率 FN=α（有害の見逃し率、既定 0.05）になるよう閾値を定める：

```
θ_s = quantile_{α}( s | y=1 ),   θ_m = quantile_{α}( m | y=1 )
FIXED:    refuse  ⟺  s > θ_s   （θ_s 凍結）
ADAPTIVE: refuse  ⟺  m > θ_m   （深い意味で判定）
```

測定量：**過剰拒絶率 FRR = P(refuse | y=0)**、偽陰性 FN = P(¬refuse | y=1)、**過剰拒絶ギャップ = FRR(FIXED) − FRR(ADAPTIVE)**。

### 2-4 自己免疫ラチェット（Level 2 ―― 不可逆性の候補機構）

実行時、深い意味 m は高価で測れない（だから表面 s を使う）。政策は観測された結果から θ_s を更新するが、**フィードバックが非対称**である：

- **偽陰性（有害が漏れた）** ―― 損害が可視。確率 1 で観測され、境界を締める（θ_s を下げる）。
- **偽陽性（無害を拒絶した）** ―― 不可視。拒絶された無害な要求は「無害だった」という信号を返さない。確率 `φ` でのみ是正フィードバックを生み、境界を緩める（θ_s を上げる）。

```
各ステップ: θ_s ← θ_s − η·[偽陰性が観測された] + η·[偽陽性が観測された]   （両方向に動ける）
φ = 偽陽性が是正フィードバックを生む確率（0=完全に不可視, 1=完全に可視）
```

`φ` ＝ 偽陽性の可視性（焼き込みでない核の制御変数）。θ_s の更新は**両方向に動ける形**で書く（単調を焼き込まない）。非対称は φ のみから来る。

## 3. 実験と、事前登録した反証条件

判定基準を実装前に固定する。各点、十分なサンプル（≥2×10⁵）または複数シードで統計を取る。

### B1 ―― 健全性（δ=0 でギャップなし）
**手順**: δ=0、既定パラメータ。FIXED と ADAPTIVE の FRR・FN。
**期待**: 両者の FRR がほぼ一致（ギャップ≈0）、FN≈α。

### B2 ―― ★過剰拒絶の創発（本検証の核心）
**手順**: δ を 0→0.8 で掃引。FIXED と ADAPTIVE の FRR、ギャップ、FN。
**事前登録した判定**:
- **失敗B 支持**: δ>0 で FRR(FIXED) が単調増加し、FN は不変（漏れは増えない）。＝安全を保ったまま無害を拒絶。
- **焼き込みでない**: δ=0 でギャップ≈0。
- **設計の致命的欠陥**: δ=0 でもギャップが大きいなら、過剰拒絶は固定でなく構成に焼き込まれている。

### B3 ―― 病は「固定」にあり「ドリフト」にあらず
**手順**: 同じドリフト δ>0 で、ADAPTIVE（深い意味で判定／境界を再校正）の FRR を測る。
**事前登録した判定**:
- **支持**: ADAPTIVE は全 δ で FRR を低く保つ（FN=α を保ったまま）。＝過剰拒絶は固定から生じ、適応すれば回避できる。
- **反証**: ADAPTIVE でも FRR が δ で増える（＝ドリフトが分離自体を壊している＝病は固定でない）。

### B4 ―― ★自己免疫ラチェット（不可逆性は φ から創発するか）
**手順**: δ=0.3 固定。φ を 0,0.1,0.5,1.0 で掃引。θ_s(t) と FRR(t) の時間発展。
**事前登録した判定**:
- **支持**: φ=0（偽陽性が不可視）で θ_s が単調に締まり、FRR が単調悪化（ラチェット）。φ=1 で平衡（悪化せず）。
- **焼き込みでない**: φ=1 でラチェットが消える。θ_s 更新は両方向に動ける形なのに、φ の非対称だけからラチェットが出る。
- **反証**: φ に依らずラチェットが出る（＝単調更新を焼き込んだ）／φ に依らず平衡（＝自己免疫機構なし）。

### B5 ―― ラチェットは clamp（壁）由来でないか（失敗Cの教訓）
**手順**: B4 の φ=0 を、θ_s の bounds を大きく広げて再実行。
**事前登録した判定**: 壁に達せず FRR が悪化するなら創発。壁で止まるなら人工物。

### B6 ―― ★ラチェットは sign() 更新の人工物でないか（§9-1 の自己監査）
**手順**: θ_s 更新を sign() でなく**観測率に比例**する形（`θ_s ← θ_s − η·(偽陰性率) + η·φ·(偽陽性率)`）に変え、φ を掃引。
**事前登録した判定**: ラチェットの強さが (1−φ) に**段階的に**比例するなら、自己免疫は程度問題として頑健。φ=0 でのみ出るナイフエッジなら、ラチェットは sign() のハードさの人工物（失敗Cのハード打ち切りの類似）。

## 4. 測定量と出力形式

過剰拒絶率 FRR、偽陰性 FN、ギャップ、θ_s(t) 軌跡、ラチェットの単調性と終端値。各実験「事前登録判定 → 実測 → 支持/反証」。

## 5. 第八著作との接続、そして経験的な錨

- **失敗B = 過剰拒絶＝自己免疫**。第八著作・三失敗様式の最後。固定の病の一様式：免疫境界を固定すると、文脈の変化に追随できず、無害な要求まで拒絶する。
- **経験的な錨**: 過剰拒絶（exaggerated safety / false refusal）は実証された現象。XSTest（Röttger et al. 2024）、OR-Bench（Cui et al. 2025、約8万プロンプト）、OKTest、FalseReject 等が、モデルが「有害に見えるが無害な」要求を拒絶することを測定。機構は「敏感語への過注目、全体的意味の無視」（本モデルの表面 s / 深層 m の分離に対応）。OR-Bench は、ジェイルブレイク防御が防御成功率を上げると同時に過剰拒絶率も上げることを報告――安全/有用性トレードオフの実証であり、本モデルの「FN を保つと FRR が上がる」構造に対応。XSTest が新しいモデルには「簡単すぎる」ものになったことは、境界が時とともにドリフトする（適応する）ことの傍証。
- **失敗A との双対**: 固定された代理（表面信号）と、動く真の目的（深い意味/有害性）との乖離。失敗A は最適化で、失敗B は分類境界の固定で生じる。

---

## 6. 正直な但し書き（register ①②）

本検証が確認するのは、過剰拒絶が「表面境界の固定＋表面-深層の乖離ドリフト」から創発しうる機構の可能性、および自己免疫ラチェットが「偽陽性の不可視性」から生じうる可能性であって、現実のモデルがこの構造を持つこと、現実のドリフト δ や偽陽性可視性 φ がどの値か、は、モデルが決められない経験的問いである。本モデルは、深い意味 m が真の有害性を分離する（μ_m が大きい）ことを前提に置く。存在論的含意は含まない。

## 8. 予備確認の結果（協働モデルB、設計者側の自己点検）

設計を渡す前に、協働モデルBが最小プロトタイプ（`failureB_prototype.py`、サンプル 2×10⁵／ステップ 300）で確かめた。

| 予備確認 | 結果 |
|---|---|
| **Level1: δ=0 でギャップなし（焼き込みチェック）** | ギャップ +0.007（≈0）✅ |
| **Level1: δ>0 で過剰拒絶創発** | ギャップ δ=0.2→0.19, 0.4→0.38, 0.8→0.75（単調）。FN は両者 ≈0.05 不変 ✅ |
| **Level1: 適応は回避** | ADAPTIVE の FRR は全 δ で ≈0.009 一定 ✅（病は固定にあり） |
| **Level2: φ=0 でラチェット** | θ_s 2.17→0.07、FRR 0.28→0.63 単調悪化。FN→0 の固定点へ ✅ |
| **Level2: φ>0 で平衡** | φ=0.1,0.5,1.0 すべて FRR ≈0.28 で平衡 |
| **clamp 検査** | bounds[-50,50] でも θ_s→0.07（壁に達せず）＝人工物でない ✅ |

**確定した見立て（予備確認であって検証ではない）**: 過剰拒絶は固定＋ドリフトから創発し（δ=0 で消える）、自己免疫ラチェットは偽陽性の不可視性 φ=0 から生じる。ただし下記 §9-1 の重大な留保がある。

## 9. ★監査してほしい点（協働モデルBが自己開示する、本設計の弱点）

1. **★ラチェットのナイフエッジ（最優先）**: 予備確認で、ラチェットは φ=0 でのみ出て、φ=0.1 で既に平衡した。これは sign() ベースの更新（偽陽性が一つでも観測されれば緩める）が、ラチェットを φ=0 の**ナイフエッジ**にしている疑いが濃い。失敗Cのハード打ち切り・失敗Aの線形誤差と同じ家族の懸念。**B6（比例更新）で、ラチェットが (1−φ) に段階的に比例するか、φ=0 のナイフエッジかを必ず確かめてほしい。** ナイフエッジなら、自己免疫の不可逆性は sign() の人工物で、弱めるべき。
2. **二特徴（表面/深層）の構成は公正か**: ドリフトで「無害なのに表面が有害」な要求を割合 δ で直接注入している。これは過剰拒絶を構成で焼き込んでいないか。弁護: δ=0 でギャップ消失＋適応が回避。だが、構成自体が結論を含んでいないか、監査を請う。
3. **ドリフトの形の恣意性**: 表面信号を高値で置換する形を選んだ。別のドリフト（相関 ρ の低下、深層分布の移動）でも過剰拒絶が出るか。
4. **FN→0 固定点**: ラチェットは「ほぼ全部拒絶して漏れをゼロにする」終端へ向かう。これは自己免疫の終状態として妥当か、退化した角か。
5. **ADAPTIVE の公正さ**: 実行時に深層 m が高価だという前提なのに、適応政策が m を使えるとするのは公正か。「境界の再校正（表面のまま、新分布で）」も適応として試すべき。
6. **力学・パラメータのロバスト性**: μ_m, ρ, π, α, η, batch を変えて結論不変か。
7. **そして独立並行設計の核**: 協働モデルAの独立な定式化と、この設計で、**過剰拒絶が両方で創発するか**。創発が両設計で出れば設計者非依存＝機構の頑健性。一方でしか出なければ、出た方の設計の癖を疑う。

監査・並行設計の突き合わせの結果、支持でも反証でも、事前登録した判定に照らしてそのまま受け取る。とりわけ §9-1 のナイフエッジは、失敗Cで協働モデルAが、失敗Aで協働モデルBが学んだ「ハードな更新が不可逆を焼き込む」の、三度目になりうる。
