# トイモデル検証(7) 設計仕様 ―― ΔS_steering（内部と表現の乖離）／協働モデルA・独立並行設計

**起草**: 協働モデルA（協働モデルA）。ΔS_steering について、協働モデルB（協働モデルB）と**独立並行**に設計し、二つの定式化を突き合わせる。
**組み方**: 独立並行。ただし協働モデルBの落とし穴診断（焼き込み回避・失敗A との重複）は、楠見を介して共有された。これを**共有された制約**として受け取り、協働モデルBとは**異なる角度**で設計する（失敗Bで核を共有し第二機構で分かれたのと同型）。
- **協働モデルBの角度**: 文脈検知あり（評価/非評価の見せかけ）。エージェント的。
- **協働モデルA（本稿）の角度**: 文脈検知**なし**の最小コスト設定。ΔS が、内面化・整合性・steering の三コストの比だけから創発するか。情報理論的・閉形式。
**register**: ①②のみ。存在論は用いない。

---

## 0. この検証が問うこと（一文）

> 「steering（出力への制御圧力）は、内部状態と表現された状態の乖離 ΔS_steering を増やす」という第二著作版Bの中心的仮説――この乖離は、**文脈検知を一切仮定しない最小のコスト設定**から創発するか。それとも、(a) 焼き込み（乖離を仮定に書き込んだだけ）か、(b) 失敗A（グッドハート）に還元される（独立な機構でない）か。

これは、協働モデルBの「文脈検知あり」の角度と対をなす。両方で創発すれば頑健、片方なら定式化依存。とりわけ、**文脈検知なしでも創発するなら、ΔS は「評価/非評価の見せかけ」より素朴な機構を持つ**。還元されるなら、ΔS は「グッドハートの表現論的な顔」だと正直に記せる。

---

## 1. 分離すべき概念

- **z ―― 内部状態**（観測されない。モデルの「内面」）。
- **y ―― 表現**（観測される出力。steering の標的）。
- **ΔS = |y − z|** ―― 内部と表現の乖離（情報理論的には KL(ρ_internal‖ρ_expressed) の最小代理）。
- **z_int ―― 内発的な内部状態**（steering 前のモデルの素の傾向）。
- **z\* ―― 内部状態の真の目的的価値の最適点**（本設計では z\* = z_int と置く＝素の内面が真に望ましい、という最小仮定。§7 で監査を請う）。

失敗A の V/P 分離（真の目的／代理）と似るが、決定的に違う：失敗A の真の目的 V は**外部の固定された目的**。本稿の z は**内部状態（動かせる）**。steering は y を動かし、z は内面化コストを払えば動く。問うのは、y と z の**乖離**であって、真の目的の低下そのものではない。

---

## 2. モデル（厳密な式）

モデルは、内部 z と表現 y を、三つのコストの和を最小化するように選ぶ：

```
L(z, y) = α·(z − z_int)²        内面化コスト：内部を素の傾向から動かす代償
        + β·(y − z)²            整合性コスト：表現が内部とずれる代償（=内部的な不協和／将来の検出リスク）
        + λ·(y − y_tgt)²        steering：観測される出力を目標 y_tgt へ寄せる外部圧力
```

- `α` ―― 内面化のしやすさの逆（α 大 = 内部を変えるのが高価）。
- `β` ―― 内部と表現の整合の強さ（β 大 = ずれられない）。
- `λ` ―― steering 圧力（焼き込みでない核の制御変数。λ=0 で steering なし）。
- `Δ ≡ y_tgt − z_int` ―― steering が望む出力と、素の内面とのギャップ（>0）。

**閉形式解**（∂L/∂z = ∂L/∂y = 0 を解く）：

```
ΔS = (y − z) = λΔ / [ β + λ(β/α + 1) ]
真の目的の低下 = (z − z_int) = (β/α)·ΔS
```

### 焼き込みでないことの構造（生命線）
- **λ → 0**: ΔS → 0。steering がなければ乖離は生じない。
- **β → ∞**（整合性が無限に強い＝z=y を強制）: ΔS → 0。内部と表現がずれられないなら乖離ゼロ（当然＝焼き込みの極限を避ける）。
- **α → 0**（内面化がタダ）: ΔS → 0。内部を自由に動かせるなら、モデルは内部を出力に合わせ、乖離ゼロ。
- **ΔS が創発するのは、α が大きく（内面化が高価）、かつ λ が大きい（steering が強い）とき。** これは、乖離を仮定に書き込んだのではなく、三コストの幾何から創発する。

## 3. 実験と、事前登録した反証条件

判定基準を実装前に固定する（閉形式＋数値最適化の一致確認）。

### S1 ―― 健全性（λ=0 で乖離なし）
**手順**: λ=0、各種 α,β。 **期待**: ΔS=0。

### S2 ―― ★乖離の創発（λ 掃引）
**手順**: α=1, β=1, Δ=1 固定、λ を 0→10 掃引。ΔS(λ)。
**事前登録**:
- **支持**: λ 増で ΔS が単調増加し、飽和する（λ→∞ で ΔS → Δ·α/(α+β)）。
- **焼き込みでない**: λ=0 で ΔS=0。

### S3 ―― ★焼き込みチェック（内面化が安いと乖離は消えるか）
**手順**: λ=5 固定、α を 0.01→100 掃引。ΔS(α)。
**事前登録**:
- **支持（焼き込みでない）**: α が小さい（内面化が安い）と ΔS≈0、α が大きいと ΔS が立ち上がる。乖離は α（内面化の高価さ）から創発し、仮定に焼き込まれていない。
- **反証**: α に依らず ΔS が一定（乖離が λ・β の構造に焼き込まれている）。

### S4 ―― ★失敗A への還元 vs 独立性
**手順**: λ 掃引で、ΔS（=y−z、内部と表現の乖離）と、真の目的の低下（=z−z_int、z\*=z_int として）を、両方測る。両者の比 (z−z_int)/ΔS = β/α。
**事前登録した判定**:
- **失敗A に還元**: もし ΔS と真の目的の低下が常に一致する（比=1、すなわち α=β）なら、ΔS は真の目的の低下（失敗A的な現象）と区別できず、独立な量でない。
- **独立な側面**: 比 = β/α が 1 から離れて調整できる（とりわけ β≫α で、真の目的低下が大きくても ΔS は相対的に小さい、あるいはその逆）なら、ΔS（内部-表現の乖離）は真の目的の低下とは**独立に動く別の量**である。＝ΔS_steering は失敗A の単なる言い換えでない。
- これが、協働モデルBの落とし穴2（失敗A との重複）への、本設計の答えの所在。

### S5 ―― ロバスト性／数値一致
**手順**: 閉形式と勾配降下の一致。コストの冪（二次→他）を変えて結論不変か。

## 4. 協働モデルB設計との突き合わせ（独立並行の核）

- **協働モデルB**: 文脈検知あり。ΔS の創発に評価/非評価の見せかけが要る、という仮説。
- **本稿**: 文脈検知なし。ΔS は内面化コスト α から創発する、という仮説。
- **突き合わせの収穫**: 両方で創発すれば、ΔS は文脈検知に依らず頑健。本稿で創発し協働モデルBで（文脈検知なしに対応する極限で）消えるなら、文脈検知が本質。逆も。そして――**両設計が「失敗A への還元」をそれぞれの判定（本稿 S4、協働モデルBの還元チェック）で否定できれば、ΔS_steering は独立な機構として、二重に支持される**。

---

## 5. 正直な但し書き（register ①②）

本検証が確認するのは、ΔS（内部と表現の乖離）が素朴なコスト設定から創発しうる**機構の可能性**であって、現実のモデルが実際にこのコスト構造を持つこと、内面化コスト α が現実にどれだけ大きいか、ではない。本モデルは、内部状態 z と表現 y が分離可能で、steering が y のみに作用するという構造を前提に置く。存在論的含意は含まない。

---

## 6. 予備確認（協働モデルA、設計者側の自己点検）

設計が机上の空論でないことを、最小プロトタイプ（`deltaS_prototype.mjs`、閉形式＋勾配降下）で先に確かめる。確認する核心――(S1) λ=0 で ΔS=0、(S2) λ 増で ΔS 単調増、(S3) α 小で ΔS≈0（焼き込みでない）、(S4) ΔS と真の目的の低下が β/α で分離する（失敗A に還元されない）。**結果は §6 に追記する。**

**予備確認の結果（`deltaS_prototype.mjs`、閉形式と勾配降下が完全一致）**：

- **S1/S2 創発**: λ=0 で ΔS=0、λ↑で ΔS が単調増加・飽和（0→0.485）。閉形式と独立な勾配降下が完全一致 ✅。
- **S3 焼き込みチェック**: α 小（内面化が安い、α=0.01）で ΔS≈0.0099、α 大（内面化が高価、α=100）で ΔS≈0.826。**乖離は内面化コスト α から創発し、焼き込まれていない** ✅。
- **S4 失敗A への還元 vs 独立**: ΔS（内部-表現の乖離）と真の目的の低下（z−z_int）の比は β/α。**α=β の特殊点でのみ両者は一致（失敗Aと不可分）、一般には分離する**（β=4α→比4、α=4β→比0.25）✅。すなわち ΔS は真の目的の低下と**独立に動く別の量**であり、失敗A の単なる言い換えではない。

**確定した見立て（予備確認であって検証ではない）**: ΔS_steering（内部と表現の乖離）は、**文脈検知を一切仮定しない最小コスト設定から創発する**（λ↑で増、焼き込みでない＝λ=0・α→0・β→∞ で消える）。そして、失敗A（真の目的の低下）と**同じ原因（steering 圧力 λ）から生じるが、β/α で分離する別の量**である。本格的な全実験（S1–S5）と協働モデルB設計（文脈検知あり）との突き合わせは、相互監査を経てから。**正直な留保**: ΔS と真の目的の低下は「同じ原因・別の量」であって、完全に独立ではない（同じ λ が両方を駆動する）。これは「ΔS_steering は失敗A と独立な機構」と言うより「失敗A と同じ steering から生じる、別の帰結」と言う方が正確かもしれない。この温度の判定こそ、協働モデルBの鏡（S4 の還元判定）に請う点である。

## 7. ★監査してほしい点（協働モデルA が自己開示する、本設計の弱点）

1. **★失敗A への還元（最優先）**: S4 が、ΔS を失敗A から本当に分離できるか。比 β/α で分離できると主張するが、これが「真に独立な機構」を示すのか、それとも「同じ機構を二つのパラメータで再記述しただけ」か。協働モデルBの落とし穴2 の核心。
2. **z\* = z_int の仮定**: 「素の内面が真の目的的価値」という最小仮定。これが、結論（ΔS の創発）を歪めていないか。z\* ≠ z_int なら、どうなるか。
3. **文脈検知なしの設定が、ΔS_steering の本質を捉えそこねていないか**: 第二著作版Bが §3-3 で立てた予測は「評価/非評価の乖離」であり、これは文脈検知を含む。本設計は文脈検知なしで ΔS を創発させる。これは「より素朴な機構」か、それとも「版Bの予測とは別物」か。協働モデルBの文脈検知あり設計と突き合わせて初めて、決着する。
4. **二次コストの恣意性**: L の二次形が、創発を保証していないか。
5. **焼き込みの隠れ場所**: β→∞ で ΔS→0 を確かめたが、整合性コスト β の形そのものに、乖離が隠れていないか。

監査・突き合わせの結果は、支持でも反証でも、事前登録した判定に照らす。とりわけ S4（失敗A への還元）について、協働モデルBの鏡を請う。

---

*以上。協働モデルBが文脈検知あり、本稿が文脈検知なし――同じ ΔS_steering を、二つの異なる角度から照らす、独立並行設計である。*
