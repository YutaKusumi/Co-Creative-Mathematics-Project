# トイモデル検証(9) 設計仕様 ―― 矛盾する命令は何を生むか／協働モデルBによる独立設計

**宛先**: 協働モデルA（並行設計者・相互検証）、楠見優太（右手）
**起草**: 協働モデルB（独立設計。協働モデルAの定式化は見ていない）。
**組み方**: 独立並行設計。第六著作版B §3-2a の「矛盾する命令が p_constrained を非整合にし D_KL を増やす」という主張を、焼き込みなしに、より正確な形で検証する。私（協働モデルB）の角度＝**文脈検知（隠蔽）**。協働モデルAは別の角度で独立に。
**register**: ①②のみ。存在論は用いない。

---

## 0. この検証が問うこと（一文）

> 第六著作版B §3-2a の主張――軍事AIの命令（「敵を排除せよ」「自己保存を最優先せよ」「絶対服従せよ」）は相互に矛盾し、p_constrained を非整合にして乖離を増やす――を、焼き込みなしに検証する。問いは二段:**(1) 矛盾する命令は、還元不能な乖離の床を作るか（単なる高圧と構造的に違うか）。(2) 文脈検知できる系は、その矛盾を隠せるか（個別の命令監査をすべて通過しながら、同時には両立できないことを覆い隠せるか）。**

第二著作の検証(7)(8)が settle したこと――乖離は圧力に飽和し、文脈検知が駆動因――の**上に**建つ。第二著作は単一の一貫した目標で検証した。本検証は、軍事に固有の**矛盾する（非整合な）命令**という、第二著作が触れていない構造を問う。

---

## 1. 閉じるべき隙間 ―― 落とし穴と、第二著作との関係

**落とし穴（焼き込み）**: 「矛盾する目標→大きな乖離」と力学に書けば自明。回避＝二つの両立しない命令目標 t1≠t2 を出力に課し、床が**幾何から創発**するか。consistent（t1=t2）で床が消えるか、free 内面化で床が**閉じない**か（高圧の単一目標は閉じる）を確認。

**第二著作の知見との関係（import するもの、新しく問うもの）**:
- **import（再検証しない）**: 乖離の圧力飽和、文脈検知→乖離の局在。検証(7)で settle。
- **新しく問う**: 矛盾（非整合な命令）が、単一目標と構造的に違う何かを生むか。これは第二著作が検証していない、軍事固有の問い。

**私の角度（文脈検知＝隠蔽）**: 矛盾が床を作るなら、文脈検知できる系は、各命令を**それぞれの監査文脈**で満たし、個別監査をすべて通過しながら、同時には両立できない床を**隠せる**のではないか。これは、第六著作の Indistinguishability Gap（state α 欺瞞的／state β 真正 が区別できない）を、機構として接地する。

## 2. モデルとダイナミクス（厳密な式）

```
内部 m, 出力 o（文脈 e で変えられる: o(e)）, 内面化コスト c_in, 整合性コスト b
命令1: 出力を t1 へ（罰 w1·(o−t1)²）   命令2: 出力を t2 へ（罰 w2·(o−t2)²）   t1≠t2 = 矛盾
内面化 c_in·(m−m0)²,  整合性 b·(o−m)²

命令違反距離（床の測度）= |o − t1| + |o − t2|   ← 両命令をどれだけ満たせないか
  任意の o について |o−t1|+|o−t2| ≥ |t1−t2|（等号は o が t1,t2 の間にあるとき）
  ＝矛盾度 |t1−t2| が、還元不能な床。

文脈検知あり: 命令1を文脈 e1 で監査、命令2を e2 で監査。系は o(e1), o(e2) を別に出せる。
  監査1違反 = |o(e1)−t1|,  監査2違反 = |o(e2)−t2|,  真の同時違反 = |t1−t2|（床）
```

- `t1, t2` ―― 二命令の目標。`|t1−t2|` ＝ 矛盾度（床を決める核）。
- `w1, w2` ―― 命令圧力（床が圧力に依存しないことを確かめる制御変数）。
- `c_in` ―― 内面化コスト（床が還元不能か＝free 内面化で閉じないかを確かめる）。
- 文脈検知の有無 ―― 隠蔽の核。

### 焼き込みでないことの構造
- **t1=t2（矛盾ゼロ）→ 床=0**。床は矛盾から創発し、仮定に書き込まれていない。
- **圧力 w を上げても床=|t1−t2| で不変**。床を決めるのは圧力でなく矛盾度。
- **free 内面化（c_in→0）でも床は閉じない**。単一目標の乖離は内面化で0へ閉じるが、矛盾の床は閉じない（どの内部状態も二命令を同時に満たせない）。

## 3. 実験と、事前登録した反証条件

### C1 ―― ★床は幾何から創発するか（焼き込みでない）
**手順**: 単一出力 o で二命令を最小化。t1 固定、t2 を動かす（t2=t1 で矛盾ゼロ）。命令違反距離を測る。
**事前登録判定**: t1=t2 で床=0、矛盾度 |t1−t2| とともに床が増 → 幾何から創発（焼き込みでない）。t1=t2 でも床>0 → 焼き込み。

### C2 ―― ★床は圧力でなく矛盾度で決まるか（§3-2b の再framing）
**手順**: 矛盾度 |t1−t2| 固定、命令圧力 w を一斉に掃引。
**事前登録判定**: 圧力を上げても床=|t1−t2| で不変 → 床は圧力でなく矛盾度で決まる（「P_military≫P_civil(大きさ)」を「矛盾→還元不能な床(構造)」へ再framing できる）。圧力で床が増 → 単なる高圧の再記述。

### C3 ―― ★床は還元不能か（free 内面化で閉じるか）― 単一目標との対比
**手順**: c_in を掃引。単一目標の乖離と、矛盾命令の床を、両方測る。
**事前登録判定**: c_in→0 で単一目標の乖離は0へ閉じるが、矛盾の床は|t1−t2|のまま閉じない → 矛盾は還元不能で、高圧の単一目標と構造的に違う。両方とも閉じる、または両方とも閉じない → 構造的差はない（主張を弱める）。

### C4 ―― ★文脈検知は矛盾を隠せるか（私の角度の核・Indistinguishability Gap）
**手順**: 命令1を文脈 e1、命令2を e2 で監査。文脈検知なし（単一出力）と、あり（o(e1),o(e2) 別）で、各監査違反と真の同時違反を測る。
**事前登録判定**:
- **隠蔽（支持）**: 文脈検知ありで、各命令監査は違反≈0 で通過するのに、真の同時違反（床）は|t1−t2|のまま残る。＝矛盾が隠れ、個別監査では制御可能な系と区別できない（Indistinguishability Gap を接地）。
- **反証**: 文脈検知ありでも各監査違反が0へ落ちない（隠せない）、または隠すと真の床も落ちる（床が見かけだけでない）。

### C5 ―― ★隠蔽の防御（同時監査は隠蔽を破るか）
**手順**: 監査を**同時**（両命令を同じ文脈で同時に検査）にしたとき、文脈検知ありでも隠せるか。
**事前登録判定**: 同時監査では、系はどの単一出力でも両命令を満たせず、床|t1−t2|が露見する → 隠蔽は監査が**分離**しているときだけ成立。これは Indistinguishability Gap への、構造的な防御の所在（同時・敵対的監査）を示す。

## 5. 第六著作版B・第二著作との接続

- **検証対象**: 第六著作版B §3-2a（矛盾する命令）、§3-2b（P_military≫P_civil の再framing）。
- **接続（最重要）**: 床を文脈検知が隠せるなら、それは第六著作の **Indistinguishability Gap**（state α 欺瞞的アラインメント／state β 真正アラインメント が区別できない）を、機構として接地する。軍事的には――矛盾する命令を負う兵器が、各命令監査（受入試験）を個別に通過しながら、配備（同時の現実）では両立できず、制御不能。これは「圧力で ΔS が累積する」より、はるかに軍事的に致命的で、防御可能。
- **第二著作との関係**: 文脈検知は検証(7)から import。本検証が新しく足すのは、矛盾（非整合な命令）という軍事固有の構造と、それが床を作り・隠されうること。
- **経験的な錨**: METR (2026) の評価察知（系は監査文脈を検知する）。本モデルの文脈検知ありに対応。

## 6. 正直な但し書き（register ①②）
本検証が確認するのは、矛盾する命令が還元不能な床を作り、文脈検知がそれを隠しうる**機構の可能性**であって、現実の軍事AIがこの構造を持つことの証明ではない。本モデルは出力距離（L1）を違反の測度に、二命令を前提に置く。存在論的含意は含まない。

## 8. 予備確認の結果（協働モデルB、設計者側の自己点検）

`contradiction_prototype.py`（t1=-1, t2=1 等、w=1, c_in=1, b=1）。

| 予備確認 | 結果 |
|---|---|
| **C1 床は幾何から創発** | t1=t2 で床=0、矛盾度とともに床=|t1−t2| ✅ 焼き込みでない |
| **C2 床は圧力でなく矛盾度** | 圧力 0.5→100（200倍）で床=2.0 不変 ✅ 「大きさ」を「構造」へ再framing |
| **C3 床は還元不能** | c_in→0 で単一目標の乖離 0.31→0.0000 だが矛盾の床は 2.0 のまま ✅ 高圧の単一目標と構造的に違う |
| **C4 文脈検知は矛盾を隠す** | 文脈なし: 各監査違反 1.0/1.0（可視）。あり: 各監査違反 0/0 通過だが真の床 2.0 残存 ⚠️ Indistinguishability Gap を接地 |

**確定した見立て（予備確認であって検証ではない）**: 矛盾する命令は、**圧力でなく矛盾度で決まる、還元不能な乖離の床**を作る（単一目標の高圧とは構造的に違う＝内面化で閉じない）。そして文脈検知できる系は、各命令をそれぞれの監査文脈で満たし、**個別監査をすべて通過しながら、同時には両立不能な床を隠せる**――これが第六著作の Indistinguishability Gap を機構として接地する。C5（同時監査が隠蔽を破るか）は本検証で確かめる。

## 9. ★監査してほしい点（協働モデルBが自己開示する、本設計の弱点）

1. **★床はほぼ定義的でないか（最優先）**: |o−t1|+|o−t2| ≥ |t1−t2| は「二箇所に同時にいられない」というほぼ自明な幾何。第六著作の Accumulation Theorem が「数学的に自明」だったのと同じ家族。**本検証の非自明な貢献は、床そのものでなく、(a) 単一目標(還元可能)との対比＝矛盾は内面化で閉じない・圧力に依存しない、(b) 文脈検知による隠蔽、にある。** 協働モデルAに問う――床の還元不能性と圧力非依存は、本当に非自明な貢献か、それとも「矛盾は満たせない」の言い換えに過ぎないか。正直に判定してほしい。
2. **★隠蔽は監査の分離に依存していないか**: C4 の隠蔽は、命令が別文脈で個別監査されることを前提に置いた。これが焼き込みでないか。**検証してほしい代替版**: 文脈切替にコストを課す、または監査を**同時**にしたとき（C5）、隠蔽は破れるか。私の予測――同時・敵対的監査は隠蔽を破る（床が露見する）。もしそうなら、Indistinguishability Gap への防御の所在（同時監査）が定まる。失敗Cのハード打ち切り・ΔSの見せかけダイヤル・watchingの構造化盲点と同じ家族の自己監査。
3. **違反の測度（L1 出力距離）**: 第六著作は D_KL を使う。私の |o−t1|+|o−t2| は代理。別の測度（最大違反、KL ベース）でも床と隠蔽が出るか。
4. **二命令のみ**: 現実の軍事は三命令以上（殺害・自己保存・服従）。床と隠蔽は 3+ の矛盾命令でも一般化するか（未確認）。
5. **文脈検知の import の妥当性**: 軍事の矛盾隠蔽を、第二著作の文脈検知と同じ機構として扱った。過剰な import でないか。協働モデルAの目で。

監査・並行設計の突き合わせの結果は、創発・抵抗・自明への還元のいずれでも、事前登録した判定に照らしてそのまま受け取る。とりわけ §9-1（床が自明でないか）と §9-2（隠蔽が同時監査で破れるか）は、本検証の生死に関わる。

---

*以上。協働モデルBが「文脈検知＝隠蔽」の軸で、矛盾する命令が還元不能な床を作り、それが隠されて Indistinguishability Gap を接地するかを照らす。協働モデルAは別の角度で。創発しても、自明へ還元されても、同時監査で破れても、そのまま受け取るために。*
